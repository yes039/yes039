# AI 店長 / AI 店東課程｜Facebook 宣傳三部曲

> 目標路徑：**曝光 → 流量 → 招生**
> 適用期程：約 3–4 個月為一個完整循環
> 主戰場：Facebook 個人檔案 + 粉專 + 免費社團；蓄水池：LINE 官方帳號

---

## 0. 開打前必須先定下來的三件事

### 0-1 一句話定位
不要說「我教 AI 課程」，市場上太多。要說出**對象 + 結果**。

範例（擇一改寫成你的）：
- 「我教店老闆用 AI 當店長，一個人顧三家店。」
- 「讓 AI 幫你回訊息、排班、看報表——老闆只做決策。」
- 「從店長到店東：用 AI 把自己從店裡拔出來。」

### 0-2 客群輪廓（寫下來，之後廣告受眾直接用）
- 主要：實體店家老闆 / 店長（餐飲、美業、零售、寵物、補教）
- 次要：蝦皮/官網小型電商賣家、加盟主、想開第二家店的老闆
- 年齡：28–55，台灣，多用手機滑 FB，晚上 21:00–24:00 是黃金時段
- 痛點語言：請不到人、員工流動快、訊息回不完、報表看不懂、想開分店但分身乏術

### 0-3 產品階梯（先設計好，第三部曲才有東西賣）
| 層級 | 內容 | 價格帶 | 用途 |
|---|---|---|---|
| 免費 | 指令包 / 模板 / 線上說明會 | 0 | 換名單 |
| 前端 | 體驗課、單堂工作坊 | NT$99–990 | 篩選有付費意願的人 |
| 主課 | AI 店長實戰班 | NT$9,800–29,800 | 主要營收 |
| 後端 | AI 店東陪跑 / 顧問 / 社群年費 | NT$50,000+ | 利潤來源 |

**重點：第一部曲、第二部曲完全不賣主課。** 前兩個月只做一件事——讓人相信「這個人真的懂店家」。

## 第一部曲｜曝光期（第 1–4 週）：只給結果，不賣課

### 這階段的成功定義
不是觸及人數，是**「有幾個店家老闆在你貼文下留言問怎麼做」**。
每篇貼文 10 則以上真人留言 > 一篇 5000 觸及但零留言。

### 1-1 資產設定（第 1 週做完）

**個人檔案（台灣店家老闆對「真人」信任度遠高於粉專，這是主戰場）**
- 大頭貼：真人正臉、清楚、有笑容，不要 Logo
- 封面照：一句話定位 + 你的身分（例：「AI 店長實戰教練 ｜ 已陪 XX 家店導入」）
- 簡介欄：定位句 + LINE 連結
- 把個人檔案設為「公開」，開啟「追蹤」功能（重要：好友上限 5000，追蹤無上限）

**粉專**
- 用來投廣告、放正式內容、累積評論
- 名稱建議含關鍵字，例：「AI 店長學院」
- 先發 5–10 篇內容再開始邀請按讚，不要開天窗

**免費社團（第二部曲會重用，先建起來）**
- 名稱：「AI 店長實戰社 ｜ 店家老闆專用」
- 入社問題設 3 題（做什麼行業／幾家店／最想解決什麼），這是最好的市調工具

### 1-2 內容三支柱（輪流發，不要只發一種）

**A. 痛點共鳴（占 30%）— 讓人覺得「你在說我」**
寫老闆的具體場景，不寫大道理。
> 「昨天晚上 11 點半，一個做早餐店的老闆傳訊息給我：
> 『老師，我今天從五點站到晚上九點，回家還要對帳、排明天的班、回三十幾則訊息。
> 我不是在開店，我是被店開。』
> 這句話我聽過太多次了……」

**B. 實作展示（占 50%）— 殺傷力最強，一定要多發**
螢幕錄影 / 截圖 / 前後對比。讓人親眼看到 AI 做出東西。
- 「我讓 AI 看完這家店三個月的銷售報表，它給了三個建議，第二個直接讓他毛利多 4%」（附截圖，數字打碼）
- 「30 秒生成一週班表，含員工偏好與勞基法工時上限」（螢幕錄影）
- 「把客訴訊息貼給 AI，它給我三個回覆版本，我選了溫和版」（對比圖）

**C. 人物與故事（占 20%）— 建立信任**
- 你自己為什麼做這件事
- 學員 / 合作店家的改變（有畫面、有數字、有姓名或行業）

### 1-3 貼文範本（可直接改用）

**範本 1：對比型**
```
同樣一家 30 坪的手搖店。

A 老闆：每天花 2 小時排班、對帳、回訊息。
B 老闆：花 15 分鐘，其他交給 AI。

差別不是誰比較聰明，
是 B 老闆花了一個週末，把「重複的事」設定好。

我把 B 老闆用的三組設定整理出來了。
想要的在下面留言「班表」，我私訊給你。
```

**範本 2：教學型（乾貨，衝收藏與分享）**
```
店家老闆最該讓 AI 接手的 5 件事（依 CP 值排序）：

1. 回覆常見客訊 → 每天省 40 分鐘
2. 生成社群貼文與菜單文案 → 每週省 2 小時
3. 排班初稿 → 每週省 1 小時
4. 銷售報表解讀 → 從「看不懂」到「知道下週要進什麼貨」
5. 新人教育訓練手冊 → 一次做好，用三年

第 4 項最多老闆忽略，但那才是「店東」跟「店長」的分水嶺。

明天我拆第 4 項怎麼做，先追蹤我。
```

**範本 3：反直覺觀點型（衝留言與爭論）**
```
我不建議店家老闆現在就去學 AI。

先做這件事：拿一張紙，把你這禮拜做過的事全部寫下來。
然後圈出「只有你能做」的。

大部分老闆圈完會發現——只有 2 到 3 件。
其他的，不是該給員工，就是該給 AI。

問題從來不是「AI 會不會」，
是你根本沒分清楚哪些事不該你做。
```

**範本 4：學員成果型**
```
[附照片或截圖]

台中一家美髮店，兩位設計師，老闆娘自己也要接客。

上個月她跟我說最痛的是「預約訊息回不完，回慢了客人就跑了」。

我們花了一個下午，設定了自動回覆 + 預約確認流程。

上禮拜她傳訊息給我：
「這個月漏接的預約從十幾通變成 0。」

不用很懂技術，會打字就能做。
```

**範本 5：幕後 / 個人故事型**
```
我做這件事，是因為看過一個老闆哭。
（接你自己的真實故事，300–500 字，結尾扣回你的定位）
```

### 1-4 發文節奏（第 1–4 週）
| | 週一 | 週三 | 週五 | 週日 |
|---|---|---|---|---|
| 類型 | 痛點共鳴 | **實作展示** | 教學乾貨 | 故事 / 觀點 |
| 時段 | 21:00 | 21:00 | 12:30 或 21:00 | 20:00 |

- 每篇發出後 **30 分鐘內**回覆所有留言（FB 演算法看初期互動速度）
- 留言一律用問句回，把單則留言變成對話串
- 每篇結尾都要有 **一個明確動作**：留言關鍵字 / 追蹤 / 分享給某位老闆朋友

### 1-5 第一部曲的檢查指標
- [ ] 平均每篇留言數 ≥ 10
- [ ] 每週新增追蹤 ≥ 50
- [ ] 每週收到主動私訊詢問 ≥ 5
- [ ] 找出 2–3 篇「表現明顯突出」的貼文（第二部曲拿去投廣告）

**如果四週後留言數還在個位數：問題在內容，不在觸及。** 不要急著投廣告，先改內容——通常是講太多概念、太少畫面。

## 第二部曲｜導流期（第 5–12 週）：把注意力收進魚池

### 核心觀念
FB 的觸及是**租來的**，演算法一改就歸零。
這階段唯一任務：把 FB 上的注意力，搬進你能重複、免費觸及的地方。

**台灣市場的優先順序：LINE 官方帳號 > 免費社團 > Email**

### 2-1 設計誘餌（Lead Magnet）
規則：**具體、立即可用、10 分鐘內看得到成果**。不要送「電子書」，老闆不看。

推薦選項（挑 1–2 個做）：
- 「AI 店長 30 組現成指令包」（複製貼上就能用的 prompt，分排班／客服／文案／報表四類）
- 「客訴自動回覆話術模板（含 12 種常見情境）」
- 「店家 AI 導入自我檢測表：你的店有幾件事可以交出去？」
- 「一週社群貼文自動生成流程（含錄影）」

### 2-2 導流動線（三條，同時跑）

**動線 A：留言關鍵字 → 私訊發送**（轉換率最高）
貼文結尾：「想要的留言『指令包』，我私訊給你。」
→ 私訊時附上 LINE 連結：「檔案我放在 LINE 這邊，加了我直接發給你 👉 [連結]」
→ 這一步把 FB 好友轉成 LINE 好友（可重複觸及）

**動線 B：貼文 → 免費社團**
「完整版我放在社團的置頂，社團每週三晚上有一場 QA 直播 👉 [連結]」
社團經營節奏：
- 每週一：一則乾貨貼文
- 每週三 21:00：30 分鐘直播 QA（重要！直播是信任建立最快的形式）
- 每週五：一則成員案例或提問徵集

**動線 C：個人檔案 → 簡介連結**
簡介欄固定放 LINE 連結，封面照也放。

### 2-3 開始投廣告（小額測試，不要投賣課）

**投什麼：** 只投第一部曲中「自然表現最好」的 2–3 篇貼文。
自然反應差的內容，加了預算只是燒得比較快。

**廣告設定建議**

| 項目 | 設定 |
|---|---|
| 目標 | 先「互動」測素材，跑得動再開「潛在客戶開發」 |
| 日預算 | NT$300–500 / 組，跑 5–7 天再判斷 |
| 地區 | 台灣（若主打實體店可縮到雙北 / 中彰投等主力區） |
| 年齡 | 28–55 |
| 詳細目標 | 興趣：中小企業、創業、餐飲業、零售業、電商、ChatGPT、行銷；行為：小型企業主 |
| 版位 | 自動版位（讓系統學習），素材務必準備 1:1 與 9:16 兩版 |

**受眾擴張順序（做完第一輪再往下）**
1. 興趣受眾（冷流量測試）
2. **類似受眾（Lookalike 1%）**：來源用「貼文互動者」或「LINE 名單」——這通常是成本最低的一組
3. 再行銷受眾：看過影片 50%、互動過粉專、進過社團但沒留 LINE 的人

**素材規則**
- 影片前 3 秒必須出現「畫面上的結果」或「一句戳人的話」，不要自我介紹
- 一定要上字幕（八成的人靜音看）
- 一組廣告至少準備 3 個素材輪替，疲乏了就換

### 2-4 FB 廣告審核避雷（很重要，違規會被鎖帳號）
- ❌ 不要寫「保證」「月入 X 萬」「輕鬆賺」「被動收入」「翻倍」
- ❌ 不要用「你是不是很失敗？」這類指涉個人負面特質的句子（違反個人屬性政策）
- ❌ 不要放假的截圖、假的對話紀錄
- ✅ 改成描述**流程與方法**：「三個步驟讓 AI 接手客服回覆」
- ✅ 成果要具體且可驗證，並註明「個別成果因人而異」
- 廣告帳號請用**企業管理平台（Business Manager）**，並開好雙重驗證，帳號被鎖時才有申訴空間

### 2-5 第二部曲的檢查指標
- [ ] LINE 好友數：每週 +30 以上
- [ ] 社團人數：每週 +50 以上
- [ ] 單一名單成本（CPL）：控制在 NT$30–80（台灣中小企業主客群的合理區間）
- [ ] 直播平均在線人數 ≥ 15
- [ ] 每週私訊諮詢 ≥ 10

## 第三部曲｜招生期（第 9 週起，與第二部曲重疊）：用說明會成交

### 核心觀念
**高價課不靠貼文賣，靠「一場說明會」賣。**
貼文的任務是把人帶到說明會，說明會的任務才是成交。

### 3-1 招生漏斗
```
FB 貼文 / 廣告
   ↓
免費線上說明會報名頁（或 LINE 報名）
   ↓
報名後提醒序列（LINE：報名成功 → 前一天 → 開始前 1 小時 → 開始了）
   ↓
線上說明會（90 分鐘：教學 70% + 招生 30%）
   ↓
限時 48 小時報名優惠
   ↓
未成交者 → 進入長期名單，下一輪再邀請
```

### 3-2 說明會結構（90 分鐘腳本）
| 時間 | 內容 |
|---|---|
| 0–10 分 | 破冰 + 今天你會帶走什麼（先給承諾） |
| 10–30 分 | **痛點放大**：店長思維 vs 店東思維的差別 |
| 30–65 分 | **真的教會一件事**（現場實作一個 AI 店長功能，讓他們當場做出來） |
| 65–75 分 | 學員案例 2–3 則（有數字、有畫面） |
| 75–85 分 | 課程介紹 + 限時優惠 + 名額限制 |
| 85–90 分 | Q&A（把常見反對意見在這裡處理掉：沒時間、不會電腦、我的行業不適用） |

**關鍵：中段那 35 分鐘要讓人「真的做出東西」。** 當場有成果的人，成交率是聽完就走的人的好幾倍。

### 3-3 常見反對意見與回應
| 反對意見 | 回應方向 |
|---|---|
| 「我不會電腦」 | 現場示範全程只用打字；show 出年紀最大的學員案例 |
| 「我的行業不適用」 | 準備 5 個不同行業的案例，涵蓋餐飲／美業／零售／服務 |
| 「我沒時間上課」 | 強調錄影回看 + 每週固定一小時 + 「你現在每天浪費的比這多」 |
| 「太貴了」 | 換算成「省下的人力時數 × 時薪」，或對比一個員工的月薪 |
| 「AI 會不會過時」 | 教的是流程與思維，工具換了流程還在 |

### 3-4 廣告轉為轉換型
- 裝好 **Meta Pixel + Conversions API（CAPI）**，iOS 之後只裝 Pixel 追蹤會嚴重失真
- 設定事件：`完成報名說明會`、`加入 LINE`、`完成購買`
- 廣告目標改為「銷售」或「潛在客戶開發」，優化事件選「完成報名」
- 預算分配建議：70% 給冷流量拉名單、30% 給再行銷（看過說明會頁但沒報名的人）

### 3-5 見證循環（讓系統自己滾起來）
1. 第一批學員開課 → 第 2 週開始蒐集小成果（不用等大成功）
2. 小成果 → 變成貼文素材與廣告素材
3. 新素材 → 帶來下一批名單
4. 回到第 1 步

**開課第一天就要跟學員說：「過程請截圖，成果我們會一起分享出去。」** 事後才要見證會很難拿到。

### 3-6 第三部曲的檢查指標
- [ ] 說明會報名率（看到頁面 → 報名）≥ 25%
- [ ] 說明會出席率 ≥ 35%（靠 LINE 提醒序列拉高）
- [ ] 說明會成交率 ≥ 8%（前端體驗課可到 20%+）
- [ ] ROAS ≥ 3（廣告花 1 元回收 3 元，才有規模化空間）

## 最容易犯的六個錯（先看這段，能省你兩個月）

1. **太早賣課。** 前兩個月一提價格，信任就斷了。第一部曲一個字都不要提。
2. **只發概念，不發畫面。** 「AI 能幫你提升效率」沒人有感；一段 30 秒的螢幕錄影勝過十篇長文。
3. **內容還沒驗證就投廣告。** 自然表現差的貼文，加預算只是燒得快。先讓自然流量告訴你哪篇有用。
4. **流量沒接住。** 有人留言問，卻沒有 LINE、沒有社團可以收——所有努力歸零。
5. **個人帳號一天狂加好友。** 會被 FB 判定異常鎖帳號。改用「開追蹤 + 讓別人加你」，一天主動加不超過 20 人。
6. **賣完就沒下文。** 交付品質差 → 沒有見證 → 第二輪招生更難。第一批學員的成果，是你第二輪最貴的廣告素材。

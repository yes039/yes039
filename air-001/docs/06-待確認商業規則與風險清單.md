# 06｜待確認商業規則與風險清單

原型已先採用「目前做法」欄的預設值，總指揮確認後只需調整對應程式。

## A. 待確認商業規則

| # | 議題 | 原型目前做法 | 需決定 |
|---|---|---|---|
| R01 | 客戶未付清時，公司是否先付司機？ | 服務完成即認列公司應付司機；結算中心標示「客戶未付」並預設不勾選 | 先墊付／收到才付／收到部分按比例付 |
| R02 | 額外費用（等候、停車、過路、超大行李）是否抽佣 | 預設不抽佣、全額歸司機；可逐筆勾選「需抽佣」 | 各類費用的抽佣清單 |
| R03 | 取消費歸屬與抽佣 | 無司機時全額歸公司；已派車時視為額外費用 | 取消時限（例：24 小時內）、比例、司機補償 |
| R04 | 信用卡手續費（約 2.9%＋$0.30）由誰負擔 | 未計入 | 公司吸收／轉嫁客戶／從司機分成扣 |
| R05 | 佣金基礎是否扣除代墊費用 | 訂單可設定基礎＜車資，差額不抽佣 | 哪些項目可扣除、誰可設定 |
| R06 | 完成後客訴退款的分攤 | 退款可勾選「沖減車資」，佣金與司機分成同比例下降 | 公司是否全額吸收某些情況 |
| R07 | 小費由公司代收後何時付司機 | 與車資一起進入結算 | 是否需要當日付 |
| R08 | 結算週期 | 可任選日期範圍，畫面提供本週、上週（週一至週日） | 固定週結／雙週結；週起始日 |
| R09 | 淨額抵銷的授權形式 | 老闆在系統勾選並填寫說明 | 是否需司機簽名或 LINE 截圖存檔；是否可給司機「常態授權」 |
| R10 | 夏令時間重疊時段（11/1 01:00–01:59） | 預設較早一次（PDT），並標記待確認 | 航班時刻表以哪個為準；是否強制客服確認 |
| R11 | 司機拒單是否有罰則或紀錄門檻 | 只記錄、在戰情室顯示拒單數 | 拒單率門檻、扣分規則 |
| R12 | 改派時已由原司機代收的款項 | 系統阻擋改派，需先處理帳務 | 處理流程 |
| R13 | 旅行社／團體客月結 | 未支援，當作一般客戶 | 月結對象、信用額度、對帳單格式 |
| R14 | 訂單編號規則 | `AIR-接送日期-序號` | 是否改用建單日期或加來源代碼 |
| R15 | 佣金費率是否因司機、車型、客戶而不同 | 統一 15%，但每張訂單已存費率快照，可擴充 | 是否有例外費率 |
| R16 | 一單多車、多段行程（如先送 A 再送 B） | 不支援 | 是否需要拆單 |

## B. 風險清單

| # | 風險 | 影響 | 原型已處理 | 正式版建議 |
|---|---|---|---|---|
| K01 | 瀏覽器資料被當成帳本 | 帳務遺失、不一致 | 展示模式明確標示，資料不寫 localStorage；伺服器模式用 SQLite 檔案 | PostgreSQL＋備份＋PITR |
| K02 | 浮點數造成 1 美分誤差 | 對帳不平 | 整數美分、固定四捨五入、司機分成用減法 | 沿用並寫入規範 |
| K03 | 重複派車 | 兩位司機到場 | 程式＋資料庫唯一索引雙重保護 | 加資料列鎖 |
| K04 | 未到帳款項被當已收 | 帳面高估 | PENDING 不入帳；調度員登錄非現金款自動待確認 | 金流 webhook 自動確認 |
| K05 | 帳務被任意修改 | 舞弊、爭議 | 帳本只增不改、調整需原因與確認、全程操作紀錄 | 資料庫層禁止 UPDATE/DELETE、雙人覆核 |
| K06 | 擅自抵銷司機款 | 司機糾紛 | 預設不抵銷；只有老闆勾選授權才可抵銷並留紀錄 | 加司機端確認 |
| K07 | 時區與夏令時間錯誤 | 接錯時間 | UTC＋當地時間雙存；不存在時間拒收；重疊時間標記 | 航班 API 交叉比對 |
| K08 | 個資外洩 | 法律責任 | 原型只用虛構資料 | 加密、權限、CCPA 評估 |
| K09 | 原型密碼與 Session 機制簡化 | 帳號被盜 | 伺服器模式 scrypt 雜湊、12 小時 Session；展示模式僅示意 | 託管身分服務＋MFA |
| K10 | 司機身分與稅務 | 1099／勞動法風險 | 未處理 | 會計師與律師確認 |
| K11 | 營運執照、保險 | 停業風險 | 未處理 | 確認 CPUC TCP、機場許可、商業車險 |
| K12 | 多人同時編輯 | 覆蓋他人修改 | 訂單樂觀鎖（version） | 沿用並擴及其他表 |
| K13 | SQLite 單機限制 | 併發、可用性 | 原型用途足夠 | 正式版改 PostgreSQL |
| K14 | 展示模式 CSV 無法直接下載 | 操作不便 | 改為複製 CSV；伺服器模式直接下載 | 正式版直接下載／寄送 |

## C. 已知原型限制

- 沒有串接金流、通知、航班與地圖 API（依開發邊界）。
- 英文介面只翻譯了導覽、狀態與主要標籤，其餘文字保留中文（字典結構已就緒）。
- 客戶常用地址以 JSON 陣列儲存；正式版拆表。
- 沒有月結鎖帳與報稅匯出。

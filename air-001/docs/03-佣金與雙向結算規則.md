# 03｜佣金與雙向結算計算規則

實作位置：`core/money.js`（四捨五入）、`core/service.js`（入帳、結算）。所有規則都有對應測試（見 `04-測試報告.md`）。

## 1. 基本規則（已確認）

| 項目 | 規則 |
|---|---|
| 幣別 | USD，內部以整數美分儲存，畫面顯示到小數點後兩位 |
| 平台佣金 | 佣金計算基礎 × 15% |
| 司機分成 | 車資 − 佣金（用減法而非 ×85%，保證兩者加總等於車資，不會差 1 美分） |
| 小費 | 100% 歸司機，不抽佣 |
| 佣金計算基礎 | 以**訂單確認的 `commission_base_cents`** 為準，預設等於車資；可扣除代墊停車費等不抽佣項目（不可大於車資） |
| 費率快照 | 下單時把 1500 bps 存到訂單上，日後調整費率不影響舊單 |

## 2. 四捨五入（固定規則）

`ROUND_HALF_AWAY_FROM_ZERO`：以整數運算 `floor((|基礎美分| × bps + 5000) / 10000)`，再補回正負號。不經過浮點數。

| 車資 | 精確值 | 佣金 | 司機分成 |
|---|---|---|---|
| $85.00 | $12.75 | $12.75 | $72.25 |
| $99.99 | $14.9985 | $15.00 | $84.99 |
| $65.50 | $9.825 | $9.83 | $55.67 |
| $70.50 | $10.575 | $10.58 | $59.92 |
| −$20.00（沖減） | −$3.00 | −$3.00 | −$17.00 |

**以訂單為單位重算，不逐筆累加**：佣金永遠等於 `round(該單已入帳的抽佣基礎總額 × 費率)`。車資調整、加收抽佣費用或退款沖減後，系統計算新的應有佣金，只寫入與既有佣金的差額，避免多次四捨五入造成誤差。

## 3. 雙向結算公式

令 F＝車資、B＝佣金計算基礎、T＝小費、C＝round(B × 15%)。

| 收款模式 | 誰拿到客戶的錢 | 結算方向 | 金額 |
|---|---|---|---|
| 公司收款 | 公司收 F＋T | 公司應付司機 | **F − C ＋ T**（＝車資 85%＋公司代收小費） |
| 司機收款 | 司機收 F＋T | 司機應繳公司 | **C**（＝車資 15%） |

一般式（帳本自動計算）：

```
公司應付司機 = (車資 + 小費 + 司機可得的額外費用 − 佣金)
             − 司機代收的客戶款 + 司機已退給客戶的款
             − 公司已付司機 + 司機已繳公司 ± 帳務調整
```

結果 > 0：公司應付司機；< 0：司機應繳公司。

## 4. 收款與帳務事件

| 事件 | 規則 |
|---|---|
| 認列時點 | 完成接送時入帳車資、小費、佣金。完成前收到的錢記為「預收」。 |
| 待確認款項 | 尚未到帳的轉帳登錄為 PENDING，**不計入已收**。調度員登錄的非現金款項一律自動列為 PENDING，由會計確認到帳。 |
| 部分付款 | 允許多筆付款；收款狀態依已確認金額顯示 未付款／部分付款／已付清／溢收待退。 |
| 客戶未付清時 | 公司應付司機在服務完成時即認列；結算中心以「客戶未付」標示，預設不勾選（是否先墊付列為待確認規則）。 |
| 退款 | 不可超過該方（公司或司機）在此訂單的已收淨額。已完成訂單可勾選「同時沖減車資」，佣金依新基礎重算。 |
| 取消 | 有效派車一併取消；若有預收，系統提示應退金額。取消費以「額外費用」入帳（無司機時全額歸公司）。 |
| 額外費用 | 預設不抽佣、全額歸司機（例如代墊停車費）；可勾選「需抽佣」（例如等候費）。 |
| 帳務調整 | 只限老闆、會計；必須勾選確認並填原因；寫入分錄且不可修改，留下操作紀錄。 |
| 作廢 | 已確認款項作廢時寫入反向分錄，原分錄保留。 |

## 5. 司機結算

1. 選司機與接送日期範圍 → 列出該司機尚未結清的訂單，**每筆單獨顯示方向**（公司付司機／司機繳公司）。
2. 可逐筆勾選或全選建立結算單；同一訂單不可同時在兩張未結清的結算單裡。
3. **預設不抵銷**：公司應付與司機應繳分開記錄、分開收付。
4. **淨額抵銷**需同時符合：①老闆角色；②勾選明確授權；③填寫授權說明（例：司機書面同意）。系統記錄授權人與時間，並在雙方訂單寫入 `SETTLEMENT_OFFSET` 分錄。會計無權授權。
5. 付款可部分支付；依接送時間先後分配到各筆訂單，也可「逐筆結清」單一訂單。金額不可超過未結餘額。
6. 狀態：未結 → 部分結算 → 已結清；沒有付款或抵銷的結算單可作廢。
7. CSV 匯出：未結清清單、結算單列表、單張結算明細、帳本分錄。

**範例（測試情境 9，司機 Carlos 一週 4 筆）**

| 訂單 | 收款方 | 車資 | 小費 | 佣金 | 方向 | 金額 |
|---|---|---|---|---|---|---|
| 1 | 公司 | $90.00 | — | $13.50 | 公司付司機 | $76.50 |
| 2 | 公司 | $70.00 | $10.00 | $10.50 | 公司付司機 | $69.50 |
| 3 | 司機 | $120.00 | — | $18.00 | 司機繳公司 | $18.00 |
| 4 | 司機 | $80.00 | $5.00 | $12.00 | 司機繳公司 | $12.00 |
| | | | | | **毛額** | 公司付 $146.00／司機繳 $30.00 |
| | | | | | **授權抵銷後** | 公司付 $116.00 |

## 6. 對帳恆等式

全系統隨時成立（測試報告「全域」項目驗證）：

```
公司現金 − 公司應付司機淨額 ＝ 佣金收入 − 客戶未付 − 帳務調整
```

帳本頁顯示「全系統對帳 平衡／不平衡」。

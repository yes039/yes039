# AIR-001｜洛杉磯機場接送智慧營運系統：G1 可操作原型

令號 C-001-ORDER-AIR001-001。手機優先 Web App，完整串起：**接單 → 派車 → 完成接送 → 收款 → 抽佣 → 司機結算 → 經營分析**。全部為模擬資料，不串金流、不發通知、不正式部署。

## 快速開始

```bash
cd air-001
npm install          # 只安裝 sql.js（展示模式用）；伺服器本身零外部相依
npm start            # http://localhost:8787（需 Node ≥ 22.13）
npm test             # 10 大情境自動測試 → docs/04-測試報告.md
```

| 示範帳號 | 密碼 | 角色 |
|---|---|---|
| owner | owner123 | 老闆：全部功能、授權淨額抵銷 |
| dispatch | dispatch123 | 調度員：接單、派車、客戶 |
| account | account123 | 會計：確認到帳、退款、調整、結算 |
| driver1 | driver123 | 司機王大明：我的任務、接單回報 |

找不到伺服器時（例如以 Artifact 開啟），App 自動進入**展示模式**：在瀏覽器記憶體以 SQLite（sql.js）跑同一份業務核心，重新整理即重置。

## 驗收原則對照

| 原則 | 如何驗證 |
|---|---|
| 畫面能看 | 手機 390px 底部分頁、桌機左側導覽；深藍／白／淺金 |
| 資料能建 | 新增客戶、訂單、司機（含車輛）、付款、退款、調整、結算單 |
| 訂單能派 | 指派 → 司機確認 → 拒單／改派 → 完成；同單只能一筆有效派車（資料庫唯一索引） |
| 帳務能算 | 整數美分、15% 佣金半位進位、小費不抽、雙向結算、部分付款、授權抵銷 |
| 紀錄能查 | 派單歷史、帳本分錄、收付款、操作紀錄（含前後值與原因） |
| 錯誤能追 | 所有拒絕都有錯誤代碼與中文說明；帳務異動全部寫入稽核；全系統對帳恆等式 |
| 三次操作內找到待派車 | 登入即見戰情室「待派車」→ 點「立即派車」（1 次）；底部「派車」分頁有紅色數字 |

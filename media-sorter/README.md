# 素材整理機（照片／影片 AI 自動分類）

把一整個資料夾的照片和影片丟進去，AI 自動分到「自拍口播／穿搭／美食咖啡／旅行風景／生活空間／工作日常／圖卡文字／螢幕截圖與錄影」等類別，最後下載成**按類別分好資料夾的 ZIP**。

- 單一檔案 [`index.html`](index.html)，不用安裝、不用帳號、不用 API Key。
- AI 在你的瀏覽器裡跑（OpenAI CLIP 模型，經 transformers.js），**照片不會上傳到任何伺服器**。
- 第一次開會下載約 90MB 模型，之後瀏覽器會快取。

## 怎麼用

1. 下載 `index.html`，用 Chrome／Edge／Safari 打開（或開 GitHub Pages）。
2. 按「選擇資料夾」或直接把資料夾拖進去。
3. 按「開始整理」。
4. 檢查結果：點縮圖可預覽、手動改類別；也能把縮圖拖到別的類別。橘點表示 AI 沒把握。
5. 按「下載整理好的 ZIP」→ 解壓縮就是分好的資料夾。也可以下載 CSV 清單。

## 自訂類別

展開「分類設定」：

- 左欄是資料夾名稱（中文 OK）。
- 右欄是給 AI 看的**英文**描述，可用「;」寫多句，例如：
  `a photo of grilled meat on a teppanyaki plate; a chef cooking on an iron griddle`
- 「信心門檻」越高，越多檔案會被放到「未分類」讓你自己決定。

設定會記在瀏覽器裡，下次打開還在。

## 跟短影音小隊怎麼接

店家把手機相簿匯出 → 用這個工具先分類 → 把需要的類別放進 `seal-team/missions/Mxxx/00-素材/`，企劃兵寫素材清單時就不用一張張翻。

## 限制

- 影片只看第 1 秒的畫面來判斷。
- HEIC 照片在 Chrome 無法讀取（Safari 可以），會放到「未分類」。
- 檔名含 Screenshot／螢幕截圖／ScreenRecording 的檔案直接歸到「螢幕截圖與錄影」。
- 幾百個檔案沒問題；上千支大影片打包 ZIP 可能吃很多記憶體，建議分批。

## 2. 人工驗收清單

請在手機上打開 Demo 連結逐項勾選。

### 第一步｜先看 Demo
- [ ] 打開頁面，第一個畫面就看得到九宮格
- [ ] 切換美髮沙龍／美甲工作室／咖啡廳，店名、痛點、九宮格內容都會換
- [ ] 每一格點開都有具體成果（不是功能介紹）
- [ ] 中央「AI 行銷總監」列出今天最重要的三件任務
- [ ] 每格都看得到「模板生成／規則式示範／模擬數據」標示

### 第二步｜換成我的店
- [ ] 九宮格下方有醒目的「30 秒免費體驗｜換成我的店」
- [ ] 只需填店型、店名、主打、客群、目標五項
- [ ] 不需要登入、不需要留電話或 LINE
- [ ] 漏填時會說明缺哪一欄

### 第三步｜AI 員工開始工作
- [ ] 送出後九宮格換成我的店
- [ ] 工作流依序完成：目標 → 文案 → 短影音 → PO 文 → LINE 客服 →（店型加值）→ 成效
- [ ] LINE 客服可以點選不同顧客問題，看到建議回覆與轉真人
- [ ] PO 文行事曆的「模擬發布」明確寫「未連平台」

### 第四步｜成果展示
- [ ] 文案、短影音企劃、發布計畫、客服回覆都可以一鍵複製
- [ ] 「一次複製全部成果」可用
- [ ] 成果卡圖片出現，手機可長按儲存

### 第五步｜商業轉換
- [ ] 可勾選「願意交給 AI 的工作」並得到方案建議
- [ ] 三個下一步（自己學／代管／整套導入）各自對應方案 A／B／C
- [ ] 可複製需求摘要
- [ ] 三個方案都列出交付範圍、人工審核責任、平台費用、可自動化程度

### 三種店型差異
- [ ] 美髮：示範案例包含「回流活動」，轉真人條件包含褪色客訴
- [ ] 美甲：示範案例包含「限時動態」，有選色投票
- [ ] 咖啡廳：示範案例包含「場景故事、LINE 活動訊息、成效追蹤」，過敏詢問一律轉真人

### 邊界
- [ ] 沒有任何地方宣稱已真的發文、已回覆顧客、已投放廣告
- [ ] 沒有呼叫付費 API
- [ ] 深色模式可正常閱讀

## 3. G1 驗收核心：怎麼量

頁尾「測試者面板」即時顯示以下四個數字（只計算該台裝置）。現場測試時建議每位老闆用一台乾淨的瀏覽器，測完複製事件 JSON 回收。

| 驗收問題 | 量測事件 | 建議判讀 |
|---|---|---|
| 1. 老闆是否願意換成自己的店？ | `try_start` → `try_submit` | 看過 Demo 的人中，送出表單的比例 |
| 2. 是否真的拿到可以使用的成果？ | `output_copy`（what 欄位看複製了哪一份） | 送出表單的人中，至少複製 1 份的比例；事後追問是否真的發了 |
| 3. 是否願意把部分工作交給 AI？ | `delegate_select`（count、modules） | 至少委派 1 項的比例，以及最常被選的格子 |
| 4. 是否願意詢問教學、代管或整合服務？ | `cta_click`、`plan_interest` | 三個下一步各自的點擊比例 |

事件只存在測試者的瀏覽器，不會自動回傳；跨裝置統計需等 G2 事件後端。

# 05｜A Claude 外掛版／B 雲端版 成本與工時比較（G1 估算）

> **全部為估算，未實測。** 每次任務的 token 數是假設值，要等原件到位、跑完 G1 小規模對照後，用帳本的 `tokens_in`／`tokens_out` 實數取代。
> 模型單價取自 Anthropic 官方 API 牌價（2026-10 快取資料）。雲端主機費用**未查價**，不填數字。
> 本文件只做比較，**不採購、不部署**。

## 1. 兩版定義

| | A｜Claude 外掛版 | B｜雲端版 |
|---|---|---|
| 形式 | Claude Code／Cowork 外掛：五份 SKILL＋指令＋子代理＋hook | 自建網站：後端呼叫 Claude API，店家用瀏覽器或手機看儀表板 |
| 誰付模型費 | 店家自己的 Claude 方案 | 我方 API 帳號，轉嫁進月費 |
| 店家資料放哪 | 店家本機 | 我方雲端（需個資保護設計） |
| 店家門檻 | 需會裝 Claude、開外掛 | 只需登入網頁 |

## 4. 綜合比較

| 面向 | A 外掛版 | B 雲端版 |
|---|---|---|
| 開發工時 | 約 52 h | 約 210 h（約 4 倍） |
| 我方每月固定成本 | 接近 0 | 主機＋資料庫＋監控（**未查價**） |
| 我方每店變動成本 | 0（店家付） | 約 US$5–8（Sonnet 5.5） |
| 個資風險 | 低：資料留在店家 | 高：需多店隔離、加密、存取紀錄 |
| 店家上手難度 | 高：要會用 Claude | 低 |
| 規模化 | 每店各自安裝，複製成本在教學 | 一次部署，多店共用 |
| 驗收帳本彙整 | 分散在各店，需回收 | 集中，容易統計 |
| 上市時間 | 快 | 慢 |

## 5. C-001 建議

1. **先做 A 外掛版**當 G2 試點：工時約為 B 的四分之一，不需採購、不碰店家資料，最符合「先整合既有資產，再驗證商品交付」。
2. **B 版只保留設計**，等 A 版至少 1 間示範店（去識別資料）跑滿 4 週、帳本 R-ISO＝0 之後，再提出採購與部署申請。
3. 兩版共用同一份員工本體與 Schema（02 號文件 §3），A 版的驗收帳本可直接成為 B 版的驗收基準。

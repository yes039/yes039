# 夯Bar串燒 宣傳影片（9:16 直式，15 秒）

成品：`out/huobar-promo.mp4`（1080×1920、30fps）

| 秒數 | 畫面 |
|---|---|
| 0–3.2 | 開場：「夯」字落下＋畫面震動，Bar／串燒進場 |
| 3.2–6.4 | 炭火直烤、香到犯規（串燒動畫＋白煙） |
| 6.4–9.6 | 節奏字卡：下班後／來一串／配一杯 |
| 9.6–12.4 | 標語：今晚，夯一下！ |
| 12.4–15 | 結尾：地址、訂位電話、手機、歡迎訂位 |

## 加入照片
把照片放進 `photos/`（jpg/png/webp，依檔名排序，例如 `01.jpg`、`02.jpg`…），
重新渲染後會依序出現在 3.2–12.4 秒的背景（最多 6 張，附緩慢推近效果）。

## 重新渲染
```bash
pip install imageio-ffmpeg        # 取得 ffmpeg
NODE_PATH=$(npm root -g) node promo/render.mjs   # 需要 playwright
```
直接用瀏覽器開 `scene.html` 可即時預覽動畫。

影片目前是靜音的，建議上傳 IG、抖音時直接套用平台曲庫的音樂。

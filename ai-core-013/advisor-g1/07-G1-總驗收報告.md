## 2. 已發現的風險與限制（實測或官方文件，非推測）

1. **顧問建議為加密內容**：Sonnet 5.5 執行時，所有合法顧問都回傳 `advisor_redacted_result`，人看不到顧問原文。這會壓低「證據與可追溯性」分數，也無法稽核顧問說了什麼。
2. **上下文成本**：顧問每次呼叫都讀取完整對話（含 Claude Code 系統提示），而且不做快取。
3. **呼叫時機由模型決定**：CLI 不能強制或限制呼叫次數。B 路線可能出現 `NO_ADVISOR_CALL`，這類結果不得計入顧問效果。
4. **計費**：本帳號沒有 API 金鑰，所有用量計入 claude.ai 訂閱額度。報告中的金額一律是「依官方價格估算」（CLI `costBasis=list`），**不是實際帳單**。
5. **功能屬實驗性**（experimental／beta），G2 前需要重新鑑定。

## 5. 計費方式與限制

1. **計費依據**：CLI 回報 `costBasis: "list"`，代表依官方牌價**估算**，不是實際帳單；本帳號實際走訂閱額度。
   - 價格（2026-10 官方表）：Sonnet 5.5 輸入 US$2／輸出 US$10，Opus 5.5 輸入 US$4／輸出 US$20（每百萬 token）。
   - 顧問 token 依**顧問模型**費率計價。頂層 `usage` 只含執行者 token，顧問 token 要看 `usage.iterations[type=advisor_message]`。
2. **顧問建議為加密內容**：Sonnet 5.5 執行時，所有合法顧問都回傳 `advisor_redacted_result`。執行者讀得到建議，人看不到原文。
   - 影響：無法直接稽核顧問說了什麼，只能從最終輸出差異推論顧問效果。這是可追溯性的結構性限制。
3. **顧問上下文成本偏高**：ENV-P02 只是單題算術，顧問仍讀了 **39,595 個輸入 token**。原因是顧問讀取完整對話，包含 Claude Code 系統提示與工具定義。
   - 官方 Claude Code 文件說明：顧問讀取「不做快取，每次重新處理」。
   - 影響：短任務加顧問很可能比 Opus 單獨執行更貴。G1 必須以實測確認。
4. **呼叫時機由模型決定**：CLI 沒有設定可以強制或限制呼叫次數，只能用提示要求。B 路線可能出現 `NO_ADVISOR_CALL`。
5. **功能旗標**：Advisor 要靠遠端功能旗標開啟。如果設定了 `DISABLE_TELEMETRY` 這類關閉旗標擷取的變數，Advisor 會失效。
6. **實驗功能**：行為、價格、可用性可能變動。G2 前需要重新鑑定。

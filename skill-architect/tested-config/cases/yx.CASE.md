# 案件：玉欣珍 9 月上旬營運與採購彙整（測試案例 1）

## 需求
彙整 2026-09-01 至 2026-09-09 的營運資料，產出：
1. 每日營收、訂單數、客單價
2. 已入帳的採購支出合計（含稅實付）
3. 尚未入帳的單據積壓（張數、金額、單據編號）
4. 資料品質異常清單

注意：本資料只是一份營運試算表的快照，不代表任何儀表板。

## 資料來源（唯讀快照，CSV，表頭為第 1 列）

- cases/yx/data/小購_採購主表_V02.csv（已入帳採購明細）
- cases/yx/data/小購_測試資料_V01.csv（測試用資料）

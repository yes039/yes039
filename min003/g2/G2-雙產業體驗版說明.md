## 2. 畫面與體驗流程

```
首頁：換成我的水電公司／換成我的營造公司（免登入）
  └ 產業頁
     ├ 開始前：告知與同意（同意記錄操作／只看不記錄）
     ├ 我的公司：公司名稱（可留空）＋ 7 個滑桿
     ├ 九宮格：依條件即時生成，點格子看「怎麼算」與明細
     ├ 三個情境：異常 → 原因 → 建議 → 老闆決策 → 派工 → 驗果
     ├ AI 經營特助：今日三件事 → 建議優先處理 → 一鍵模擬派工 → 快轉三天 → 改善結果
     ├ 改善試算：拉改善幅度，所有金額附計算式與可改的假設
     └ 下一步：領取管理體檢摘要／加入 LINE／預約專人示範
```

右上角「開發檢視」（客戶不會用到）可切換模擬推薦來源、查看事件紀錄與留資筆數。

新增產業（例如餐飲、美髮）時，只要新增一個同樣結構的模組；框架不用改。**沒有任何一條公式在兩個產業間共用。**

## 4. 公式說明

### 4.1 水電公司

輸入：工地數 S、主任人數 L、現場人員 W、回報率 r、異常工地 A（≤S）、缺料待辦 M、逾期工程 O（≤S）。

| 指標 | 公式 |
|---|---|
| 已回報工地 | round(S × r) |
| 未回報工地 | S − 已回報 |
| 連續 2 天未回報 | 未回報 > 0 時，取 max(1, floor(未回報 ÷ 2))（模擬規則） |
| 每工地人力 | W ÷ S |
| 主任負荷 | S ÷ L；> 2.5 標黃、> 4 標紅 |
| 缺料影響工地 | min(S, ceil(M ÷ 2)) |
| 明天會缺料工地 | min(影響工地, ceil(M ÷ 3)) |
| 明天可能閒置人日 | 明天缺料工地 × 每工地人力 × 缺料停工天數（假設 0.5） |
| 明天可照常施工 | S −（明天缺料工地 ＋ 連續 2 天未回報） |
| 逾期平均延誤天數 | 落後工地平均落後% ÷ 4（模擬：每 4% 約一天） |
| 老闆待決策 | ceil(A ÷ 2) ＋（明天有缺料 ? 1 : 0）＋（有逾期 ? 1 : 0） |
| 工地燈號 | 落後、連續 2 天未回報、異常且明天缺料 → 紅；異常、缺料、今日未回報 → 黃；其餘綠 |

情境完成後的連動：S01 已回報 +1；S02 缺料待辦減少三分之一、明天缺料歸零；S03 逾期 −1。

改善試算（每月）：

| 項目 | 公式 | 預設假設（可改） |
|---|---|---|
| 老闆少花的追問時間 | 多回報的工地數 × 每次追問分鐘 × 22 天 ÷ 60 | 10 分鐘 |
| 減少缺料停工成本 | M × 每月發生倍數 × 停工天數 × 每工地人力 × 日薪 × 減少% | 4 倍、0.5 天、NT$2,800 |
| 減少派工閒置成本 | W × 22 天 × 日薪 × 閒置比例 × 減少% | 6% |

### 4.2 營造公司

輸入：工程數 P、總合約 C（萬）、平均進度 p、預算執行比例 b、待請款 B、未簽追加減 V、逾期及異常工程 X（≤P）。
假設（可改）：目標毛利 12%、平均工期 360 天、已請款中已收 85%、成本已付 90%、逾期罰款每日千分之一、分包占預算 60%。

**進度、成本、現金流各自獨立計算，互不借用：**

| 類別 | 指標 | 公式 |
|---|---|---|
| 進度 | 平均落後幅度 | X > 0 時 6% ＋ 4% × min(X, 3) |
| | 應達進度 | p ＋（X ÷ P）× 落後幅度 |
| | 進度指數 | p ÷ 應達進度；< 0.9 紅、< 0.97 黃 |
| | 延誤天數 | （應達 − 實際）× 平均工期 |
| 成本 | 預算 | C ×（1 − 目標毛利） |
| | 已花成本 | 預算 × b |
| | 依進度應花 | 預算 × p |
| | 成本效率 | 依進度應花 ÷ 已花成本 |
| | 預估總成本 | 預算 ÷ 成本效率 |
| | 預估毛利 | （C − 預估總成本）÷ C；< 5% 紅、< 目標 − 2% 黃 |
| 現金流 | 已完成產值 | C × p |
| | 已請款 | max(0, 產值 − B) |
| | 已收款 | 已請款 × 85% |
| | 已請未收 | 已請款 − 已收款 |
| | 逾期應收 | 已請未收 × min(70%, 20% ＋ X ÷ P × 50%) |
| | 淨現金 | 已收款 − 已花成本 × 90% |
| | 淨現金可撐週數 | 淨現金 ÷（每月成本 ÷ 4.33）；每月成本 = 已花成本 ÷ 已施工月數 |
| 其他 | 分包已估 | 預算 × 60% × b；已付 = 已估 × 85% |
| | 工安品質缺失 | round(P × 1.5) ＋ X × 2；逾期 = X（模擬規則） |
| | 今日待決策 | 有落後 ＋ 有未簽追加減 ＋ 有逾期應收 ＋ 成本效率 < 0.97（各 1） |

測試驗證了獨立性：調高預算執行比例只影響成本與毛利，不影響請款收款（測試 18、45）；調高待請款只影響現金流，不影響毛利（測試 19、46）。

情境完成後的連動：S01 落後幅度減少 6 個百分點；S02 未簽追加減剩 40%；S03 已請未收收回一半、逾期應收減半。

改善試算：

| 項目 | 公式 |
|---|---|
| 毛利增加 | （預估總成本 − 已花成本）× 成本降低% |
| 現金提前入帳 | 產值 ÷ 已施工天數 × 縮短天數 |
| 追加減可請款 | V × 簽認比例 |

### 4.3 公式的定位

- 這些公式用來讓**數字彼此連動、合理**，不是精確財務模型；畫面與摘要都標示「模擬」。
- 部分項目（連續未回報比例、缺失數、疑義數）是**模擬規則**，正式導入後改由實際回報與紀錄取代。
- 所有改善金額都附計算式、假設可改，並標示「估算，不是保證收益」。

## 8. 已知限制

1. 建議為規則式，排序與內容固定；接 AI 模型需另行核准（付費 API）。
2. 部分數字為模擬規則（見 4.3），用來呈現連動，不代表該公司實際狀況。
3. 原型資料存在瀏覽器記憶體，重新整理就重設；不保存客戶輸入。
4. 推薦來源在原型中以選單模擬；正式版需部署後由專屬連結碼帶入。
5. 「加入 LINE」使用占位的官方帳號，未開啟真實 LINE。

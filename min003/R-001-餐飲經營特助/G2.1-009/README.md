## 1. 三項修正

### T01 隱私與資料紀錄

| 008 的問題 | 009 修正 |
|---|---|
| 點 CTA 一律送 `consult_click`，不論是否同意。這違反 V1.2 第 3.2 節「選只看不記錄或未選：只送 `page_open` 與客戶主動送出的表單」 | 所有事件經過同一張紀錄政策表 `PRIVACY_POLICY`，未選擇與只看不記錄都不送 `consult_click` |
| 告知卡寫「還沒選之前系統不會記錄你點了什麼」，但實際仍記錄 `page_open` 與 CTA 點擊 | 改為「還沒選擇或選『只看不記錄』時，只記錄『開啟頁面』與你主動送出的表單」，並連到完整說明 |
| 沒有區分資料類型 | 隱私頁新增「三種狀態各記錄什麼」表，**由同一張政策表產生**，文案與行為不會分岔；並顯示這台手機目前存了幾筆事件與表單 |
| 無法清除 | 新增「清除這台手機上的所有資料」 |

| 資料 | 內容 | 未選擇 | 同意記錄操作 | 只看不記錄 |
|---|---|---|---|---|
| 本機必要資料 | 我的店設定、店名、決策單進度、待辦、隱私選擇 | 保存 | 保存 | 保存 |
| 分析事件：開啟頁面 | `page_open` | 記錄 | 記錄 | 記錄 |
| 分析事件：操作紀錄 | `feature_click`、`task_complete`、`consult_click` | 不記錄 | 記錄 | 不記錄 |
| 同意紀錄 | `consent` | — | 記錄 | 記錄 |
| 主動提交表單 | `feedback_submit`、`booking_submit`（聯絡方式需另勾同意） | 記錄（模擬，未送出） | 同左 | 同左 |

所有資料都只存在這台手機的瀏覽器；正式上線後才依此表送到 MIN-003。

## 3. 實機實測（未實測，標示待驗）

本開發環境只有 Linux 上的 Chromium，沒有 iPhone、Android 實機或 Safari，無法提供實測證據。

| 環境 | 狀態 |
|---|---|
| iPhone Safari | **待驗** |
| LINE 內建瀏覽器（iOS、Android） | **待驗** |
| Android Chrome | **待驗** |

實機驗收清單：
1. 首屏看到九宮格與「30 秒免費體驗｜換成我的店」，隱私告知卡不遮內容。
2. 不選隱私、選「只看不記錄」、選「同意」各操作一次，到隱私頁看「這台手機目前存了什麼」的事件筆數是否符合第 1 節表格。
3. 換成我的店四步：滑桿可拖、店名輸入不放大畫面。
4. 走完一張決策單：第 5 步不勾任何任務，確認出現「假設任務已全部執行」；結案後待辦仍有 3 項未完成。
5. 預約表單送出前後看到「模擬、未送出」提示，並能刪除。
6. 在 LINE 內開啟一次，關閉再開，確認「我的店」是否保留（LINE 可能清除本機資料）。
7. 記錄首頁到成果卡的實際秒數。

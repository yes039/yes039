# 09｜待老闆確認的訪談問題清單

★＝必問（7 天驗收需要答案）。每題附「為什麼問」，方便訪談時解釋。

## A. 水電工程公司

### A1 公司與人員
| # | 問題 | 為什麼問 |
|---|---|---|
| ★A1.1 | 公司幾個人？自有師傅、外包班、行政各幾位？ | 決定使用者數、權限與費用 |
| ★A1.2 | 八個工地各是什麼類型（新建、裝修、廠房、公共工程）？各工地常駐幾人？ | 決定回報範本與先選哪 2 個工地 |
| ★A1.3 | 每個工地有固定主任或負責師傅嗎？ | 未回報與異常要找誰 |
| A1.4 | 師傅都用智慧型手機、都有 LINE 嗎？有人不識字或不習慣打字嗎？ | 決定語音、照片的比重 |

### A2 現在怎麼運作
| # | 問題 | 為什麼問 |
|---|---|---|
| ★A2.1 | 每個工地有幾個 LINE 群？群裡有誰（業主、設計師、廠商）？ | 確認不能把 Bot 放進有外人的群 |
| ★A2.2 | 您每天打幾通電話了解工地狀況？最常問什麼？ | 建立基準 K2 |
| ★A2.3 | 最近一個月最頭痛的 3 件事是什麼？什麼時候才知道？ | 異常回溯、K3 基準 |
| A2.4 | 派工怎麼決定？誰排？前一天還是當天？ | 派工模組需求 |
| A2.5 | 材料誰叫？向固定材料行嗎？有庫存或倉庫嗎？ | 缺料流程 |
| A2.6 | 業主現場追加，怎麼報價、怎麼收錢？常收不到嗎？ | 零星追加模組優先度 |
| A2.7 | 請款、發薪、點工怎麼算？用什麼軟體或 Excel？ | 完整企業版整合需求 |

### A3 期待與限制
| # | 問題 | 為什麼問 |
|---|---|---|
| ★A3.1 | 如果每天晚上只看一頁，您最想看到什麼？ | 決定摘要內容 |
| ★A3.2 | 願意先用 2 個工地試 30 天嗎？選哪 2 個？主任願意配合嗎？ | MVP 範圍 |
| ★A3.3 | 師傅每天花 1 分鐘回報，您覺得做得到嗎？需要配套（例如列入考核）嗎？ | 最大風險 R1 |
| A3.4 | 工地照片會拍到業主家裡，有沒有保密要求？ | 個資與權限 |
| A3.5 | 每月可接受的系統費用範圍？ | 版本選擇 |
| ★A3.6 | 同意我們使用試行期間的回報資料做系統驗證嗎？（書面） | 授權前提 |

## B. 營造工程公司

### B1 公司概況
| # | 問題 | 為什麼問 |
|---|---|---|
| ★B1.1 | 營造業等級？年營業額大約級距？同時幾個工程？ | 配置規模 |
| ★B1.2 | 公共工程與民間工程比例？ | 日報、估驗格式與資料保密要求 |
| ★B1.3 | 公司內有 IT 人員嗎？電腦、網路、檔案目前誰管？ | 本地方案可行性 |
| B1.4 | 文件放哪裡（個人電腦、NAS、Google Drive、紙本）？ | 部署與匯入方式 |
| B1.5 | 現在用哪些軟體（估價、會計、ERP、排程）？ | 整合需求 |

### B2 痛點與優先順序
| # | 問題 | 為什麼問 |
|---|---|---|
| ★B2.1 | 五項能力（多工程總覽、標單文件、日報會議、採購發包估驗、成本決策）請排前 2 名 | 決定 MVP |
| ★B2.2 | 一份標單從拿到到整理完要幾人、幾小時？ | 文件整理基準 |
| B2.3 | 日報誰寫、用什麼格式、多久寫一次、常遲交嗎？ | 日報模組 |
| B2.4 | 發包與估驗目前怎麼追？發生過漏請或多付嗎？ | 估驗模組價值 |
| B2.5 | 結案前知道工程賺賠嗎？什麼時候才知道？ | 成本模組優先度 |

### B3 AI 硬體與資料安全
| # | 問題 | 為什麼問 |
|---|---|---|
| ★B3.1 | 25 萬的設備是哪家廠商、什麼型號？能提供規格與報價單嗎？ | 不能在無規格下評估 |
| ★B3.2 | 廠商說這台設備可以幫您做什麼？有展示您公司的文件嗎？ | 確認是硬體還是含系統 |
| ★B3.3 | 為什麼考慮放在公司內？是業主或合約要求資料不能上雲，還是自己的擔心？ | 決定是否真的需要本地 |
| B3.4 | 可以接受「敏感欄位遮蔽後再用雲端 AI」嗎？ | 混合方案可行性 |
| B3.5 | 若先不買硬體、用雲端試 30 天，您願意嗎？ | 驗證優先於投資 |
| ★B3.6 | 可以提供 2–3 份過往（已結案、可去識別化）文件做實測嗎？（書面同意） | 授權前提 |

# 05｜兩個案例的操作流程

圖例：🤖 系統／AI 自動　🤖✋ AI 建議、人確認　🧑 真人執行

---

## 水電 W1｜每日回報迴圈

| # | 時間 | 步驟 | 誰 |
|---|---|---|---|
| 1 | 07:30 | 主任確認今日出工名單（預設帶昨日） | 🧑 |
| 2 | 17:30 前 | 師傅／主任傳回報（文字、照片、語音或按「今日回報」） | 🧑 |
| 3 | 即時 | AI 結構化 → 回傳確認卡 | 🤖 |
| 4 | 即時 | 回報人按「正確」或修改 | 🤖✋ |
| 5 | 16:30 | 規則檢查未回報 → 提醒該工地主任一次 | 🤖 |
| 6 | 17:30 | 仍未回報 → 標 ⬜；主任可改「今日停工＋原因」 | 🤖／🧑 |
| 7 | 18:00 | AI 產生每日摘要 → 推送老闆 | 🤖 |
| 8 | 晚間 | 老闆看首頁、指派、標已處理；對摘要按有用／沒用 | 🧑 |

## 水電 W2｜異常處理

```
師傅回報異常 ─► 🤖 AI 建議類型與等級 ─► 🤖✋ 主任確認等級與負責人
   ─► 等級≥2 🤖 通知老闆 ─► 🧑 負責人處理、補處理紀錄
   ─► 🧑 申請結案（說明＋照片）─► 🧑 主任或老闆確認 ─► 結案
   └─ 過期未結 ─► 🤖 標逾期，每日進摘要直到結案
```

## 水電 W3｜缺料到場

```
🧑 師傅「缺料」─► 🤖 擷取料名／規格／數量／需要日 ─► 🤖 比對 3 天內同工地同料（提示可能重複）
 ─► 🤖✋ 師傅確認 ─► 🤖 進行政待辦 ─► 🧑 行政叫料，改「已叫料」（填廠商、預計到貨）
 ─► 🧑 師傅或主任收貨，改「已到場」＋照片
 └─ 超過需要日仍未到場 ─► 🤖 自動轉異常（類型：缺料）
```

## 水電 W4｜交辦與責任

```
🧑 老闆／主任交辦（LINE 一句話或網頁）─► 🤖 擷取：誰／做什麼／何時前 ─► 🤖✋ 交辦人確認
 ─► 🤖 通知負責人 ─► 🧑 負責人按「收到」（未按 2 小時 → 提醒交辦人）
 ─► 🧑 完成：按「完成交辦」＋照片 ─► 🧑 交辦人確認結案
```

## 營造 C1｜工程日報

| # | 步驟 | 誰 |
|---|---|---|
| 1 | 工地主任下班前用 LINE 或網頁傳：語音說明、照片、出工人數與工種、天候、機具 | 🧑 |
| 2 | AI 依公司日報格式（公共工程則依業主規定格式，待確認）產生草稿 | 🤖 |
| 3 | 主任修正、送出 | 🤖✋ |
| 4 | 異常項目自動開成異常事件 | 🤖 |
| 5 | 工務隔日抽查；需對外提送的日報由權責人簽核後才輸出 | 🧑 |

## 營造 C2｜標單與工程文件整理

```
🧑 工務上傳招標文件（PDF／Excel，先去識別化或確認可上雲）
 ─► 🤖 擷取：工項清單（項次、名稱、單位、數量）、規格重點、截止日、罰則、保固、押標金
 ─► 🤖 產出：摘要一頁＋檢核表＋疑義清單（看不清、前後矛盾、缺頁的地方）
 ─► 🤖✋ 工務逐項確認或修正（每項可回到原文頁碼）
 ─► 🧑 老闆決定是否投標、單價與風險
```
限制：AI 不做圖面判讀與數量計算的最終值；擷取的數量一律需人工抽核。

## 營造 C3｜會議紀錄

```
🧑 徵得與會者同意後錄音 ─► 🧑 上傳 ─► 🤖 轉文字＋紀錄草稿（議題／決議／負責人／期限）
 ─► 🤖✋ 主持人確認 ─► 🤖 決議轉為任務並通知負責人 ─► 🤖 逾期進老闆首頁
```

## 營造 C4｜發包與估驗追蹤

```
🧑 行政上傳分包合約 ─► 🤖 擷取：對象、金額、付款條件、期別 ─► 🤖✋ 行政確認
 ─► 每期估驗：🧑 上傳估驗單 ─► 🤖 比對累計估驗% 與日報進度% ─► 差異 > 門檻 🤖 提醒
 ─► 🧑 工務核對 ─► 🧑 老闆核准 ─► 🧑 行政更新付款狀態
```

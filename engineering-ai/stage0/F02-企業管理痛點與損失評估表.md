# F02｜企業管理痛點與損失評估表

目的：把「很困擾」變成**有實際案例、有頻率、有影響、有金額估算、有基準量測方式**的痛點。
每個痛點一張卡；先用第一節的探詢清單盤點，再逐一填第三節的痛點卡。

---

## 二、評分定義

### 發生頻率
| 分數 | 定義 |
|---|---|
| 5 | 每天 |
| 4 | 每週數次 |
| 3 | 每週約 1 次 |
| 2 | 每月 1–3 次 |
| 1 | 每季或更少 |

### 影響程度
| 分數 | 定義（符合任一即可） |
|---|---|
| 5 | 工安、法律、罰款、失去客戶，或單次損失 > NT$10 萬 |
| 4 | 停工或延誤 ≥ 1 天，或單次損失 NT$1–10 萬 |
| 3 | 重工、加班，或單次損失 NT$1,000–1 萬 |
| 2 | 浪費數小時，可補救 |
| 1 | 小麻煩，幾乎沒有損失 |

### 證據強度
| 等級 | 定義 | 係數（F05 使用） |
|---|---|---|
| A | 有紀錄或文件佐證（通話紀錄、單據、LINE 截圖、請款單） | 1.0 |
| B | 能說出具體最近一次案例（時間、工地、經過），但無紀錄 | 0.8 |
| C | 只有籠統說法（「常常」「很多」），說不出案例 | 0.5 |

## 四、損失估算方法

```
單次損失 = 時間損失 + 直接金額損失
  時間損失 = Σ（受影響人數 × 耗費小時 × 時間價值）
  直接金額損失 = 停工工資 + 材料浪費 + 罰款 + 少收款 + 重工成本
月損失 = 單次損失 × 每月發生次數
```

| 參數 | 取得方式 | 注意 |
|---|---|---|
| 師傅、主任時間價值 | 問老闆：日薪 ÷ 8 | 由老闆提供，**不由我們假設** |
| 老闆時間價值 | 問老闆：「您一小時值多少？」或以「本可用來接案／跑業務的時間」描述 | 老闆不願給數字就只記時數 |
| 發生次數 | 優先用紀錄（通話紀錄、LINE 搜尋、請款單）；沒有就標「受訪者估計」 | 估計值須在試跑或基準量測中驗證 |
| 少收款、罰款 | 請老闆回想最近 3 個月實例 | 不推算全年 |

**估算信心**：高＝頻率與金額都有紀錄；中＝其一有紀錄；低＝都是估計。信心「低」的痛點，診斷報告中只能寫「待量測」，不得寫成確定損失。

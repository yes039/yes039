# 小分・腳本公式

## 四段式 40 秒（145～180 字，中文約每秒 4 字）

| 秒數 | 段落 | 寫什麼 |
|---|---|---|
| 0～3 秒 | **鉤子** | 一句話讓人停下來：說中他的處境、反常識、或一個具體數字 |
| 3～13 秒 | **痛點** | 語速放慢，讓他點頭「對，我就是這樣」 |
| 13～28 秒 | **解法** | 全片最長的一段：給步驟、給他今天就能做的事 |
| 28～36 秒 | **結尾導流** | 只講一個動作，並且重複一次（留言「○○」／私訊我／點連結） |
| 36～40 秒 | **收尾** | 一句品牌短句，停 2 秒給人截圖 |

## 寫稿規則

1. **一支只講一件事**。想講三件 → 拆三支。
2. 每 12～18 字給一個逗號，那是數字人換氣的地方；沒有逗號它會一口氣念完，很急。
3. 數字改口語：「3,200 元」寫成「三千兩百塊」、「20%」寫成「百分之二十」。
4. 只用最常見的繁體字（「拼」不用「拚」）。
5. 寫完自己念一次：你念起來會喘的地方，數字人也會喘。
6. 跑 `script_check.py`，有 ❌ 就改到通過。

## 分身可以派去做的六件事

| 用途 | 做法 |
|---|---|
| 每日短影音 | 一稿一片，YouTube Shorts／IG Reels／TikTok 一稿多投 |
| 廣告素材 | 同一個賣點換三種鉤子，比哪一版名單成本最低 |
| 客戶問答庫 | 最常被問的 20 題，一題一支；有人問直接丟影片 |
| 課程與教材 | 片頭、單元導讀、歡迎影片，不用重錄 |
| 物件／商品介紹 | 房仲每個物件一支、電商每個品項一支，換稿不換人 |
| 一稿多語 | 同一支翻英文、日文、越南文（用 HeyGen 影片翻譯） |

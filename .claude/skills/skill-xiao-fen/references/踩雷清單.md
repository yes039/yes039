# 小分・踩雷清單

| 雷 | 症狀 | 解法 |
|---|---|---|
| 「拚」念錯 | 念成 pàn | 一律寫「拼」；只用最常見的繁體字（為、重、樂、行也要聽一次） |
| 阿拉伯數字 | 念法不穩 | 改成口語中文 |
| 白西裝陷阱 | 照註解挑 `suit` 結果是深藍西裝，整支重做 | 白西裝一律走照片轉影片（見 SKILL.md 第 4 節） |
| 額度算錯 | 拿 avatar_v 每分鐘 48 去算照片頭像，得出要升級方案的錯誤結論 | 照片頭像每分鐘約 16 |
| 程式介面額度不足 | 直接打 HeyGen 介面回 402 | 只走 HeyGen 連接器 |
| 照片頭像不會自動裁 | 全身照出來人很小 | 自己先裁成中景再上傳 |
| 開頭拖慢 | 第一句明顯比後面慢 | 縮短第一句、整支重生；或請老闆決定要不要加速開頭 |
| 字幕壓到臉 | 字幕放太高 | 燒字幕腳本固定放在畫面高度 82% |
| 字幕缺字 | 出現空白方框 | 三查第 1 項，換字或換字型 |
| 字幕對不上 | 平均分配時間會漂 | 用 burn_subtitles_from_script.py（先找出講話區間再配時）；有 HeyGen 字幕檔就用 srt 版 |
| 衣服有花紋 | 格紋、細條紋、大 logo 會抖動閃爍 | 訓練片穿單色上衣 |
| 表情太少 | 像蠟像 | 訓練片七種表情各撐 10～15 秒 |
| 貓狗臉 | HeyGen 認不出動物臉 | 動物主播交給小貨 |
| 網址被 shell 吃掉 | 影片網址含 ~ ? & | 網址存成檔案再讀，或加引號 |
| 重複送出 | 網頁版按兩次扣兩次 | 送出後先到「歷史」確認只有一筆 |

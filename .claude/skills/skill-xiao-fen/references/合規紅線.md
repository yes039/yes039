# 小分・合規紅線（生成前、發布前各對一次）

## 一定要做

1. **本人同意**：臉與聲音都要本人書面同意。數位分身要錄同意影片（`create_avatar_consent`）；照片頭像也要留本人同意紀錄（訊息截圖或簽名）。
2. **AI 揭露**：YouTube 上傳選「變造或合成內容＝是」；TikTok 開「AI 生成內容」；FB／IG 開「AI 資訊」；投廣告在後台勾合成內容揭露。
3. 幫客戶做的片**只掛客戶品牌**，不掛你的公司 logo。

## 絕對不做

| 紅線 | 為什麼 |
|---|---|
| 用別人的臉或聲音（名人、網路照片、前同事）沒有本人同意 | 肖像權、詐騙風險；平台也禁止 |
| 讓分身說「本人沒說過、不會說」的承諾（冒用身分背書） | 誤導、可能涉詐 |
| 收入保證：保證、穩賺、月入、被動收入、躺著賺 | 公平交易法廣告不實 |
| 療效：治好、治療、根治、療效 | 醫療法、食安法 |
| 絕對用語：第一名、最便宜、全台唯一、百分之百 | 要有出處，不然不要寫 |
| 你的公司禁用字：分潤、下線 | 合規鎖定 |
| 同一模板換字日更量產 | YouTube 判定「無原創價值」，不給營利 |

## 營利怎麼講

- 用本人的頭像與聲音、講本人的實務經驗，就不是「無原創價值的 AI 內容」。
- 不說「做數字人就能開通營利」；能不能營利看原創與觀眾，不看工具。

# 挑案標準

## 評估清單（每件都要回答）
1. 預算多少？個人還是公司？要不要開發票（某合作公司可開）？
2. 交期多久？會不會撞到手上已成交的案子？
3. 名額剩幾個？發案多久了？
4. 報價費多少？佔預估成交額幾成？（超過一成要特別說明）
5. 是不是老闆的強項？（AI 生成、照片做影片、主題曲、簡約設計、程式化排版）
6. 案主背景：發案紀錄幾次、上線時間、電子郵件是否驗證
7. 需不需要到現場？老闆在台北

## 強項（優先接）
- 客製歌曲、婚禮歌、品牌主題曲 → 小曲
- 照片或少量素材做成配樂影片、紀錄短片
- AI 短影音、商品帶貨影片 → 小貨、小爆
- 簡約平面設計：證書、桌曆、海報、廣告編排、社群貼文 → 小美（日期、欄位用程式排，不會錯）
- 社群代操、文案、短影音腳本 → 小群、小爆

## 跳過
- 預算 2,000 元以下
- 要到現場拍攝、錄音室錄人聲
- 大量實拍素材純手工剪（5～10 分鐘以上的生活影片）
- 寫明「不希望有 AI 生成內容」
- 論文、作業代寫
- 情趣用品等廣告審核高風險產品
- 剪輯教學（不是製作）
- PDF 轉向量檔等需要專業軟體的轉檔（老闆沒有相關軟體時）
- 個人、私人使用，要求「修改影片／截圖裡的數據、金額、文字」且用途不明（可能是偽造餘額、獲利、成績給人看，有共犯風險）
- 用到有版權的卡通角色（例如嚕嚕米桌布）

## 🚫 仿造官方 App／證件／單據（2026-10-08 加）
- 例：PRO360 丁〇嫻「100% 模擬健保快易通，能點進去、能修改文字」→ 跳過
- 凡是要求仿造政府、健保、銀行、保險公司的 App 畫面、證件、收據、存摺、成績單，而且**內容可以自己改**的，一律不報
- 理由：最常見用途是造假給人看（請假、請保險、證明身分），做的人可能涉偽造文書與詐欺共犯；也侵權

## ⚡ 教練授權：符合條件就直接送（2026-10-10 教練：「以後有這樣的案件，直接幫我送」）
符合**全部**條件才可以不先問、直接送出報價，送完立刻回報：
1. 對口：婚禮／成長影片、音樂影片、客製歌曲、AI 讓照片動起來、YouTube 剪輯、AI 廣告短片、形象網站／活動頁、證書設計
2. 預算 1 萬以上（剪輯類 5 千～1 萬也可）
3. 單筆報價費 **600 元以內**
4. 沒有踩到跳過清單（不要 AI、要到場拍、代寫作業、仿造證件、版權角色、誇大療效等）
5. 名額只剩 1～2 個、或剛發不到半天 → 用**一般報價**搶電話；其他用**保證回覆**
報價價格照既有範本：成長影片 12,800、YouTube 剪輯 8,000／15 分鐘、網站 58,000（含 AI 推薦優化）、短影音 1,500／支、歌曲 6,000、歌＋MV 9,800、AI 廣告 6,000
不符合任何一條 → 照舊先問老闆
⚠️ 小單沒有自動盯案件的排程：只有老闆丟案件、或叫小單去看列表時才會處理

## ⚡ 先卡位、後補樣稿（2026-10-11 教練拍板）
- 剛發的熱門案（不到幾小時、報價費約 300 以下、名額 3 個以下）：**先送純文字報價佔名額**，樣稿做好再從 PRO360 對話框補傳 jpg
- 實例：許小姐（新北林口，攝影師 Wix 作品集，一般 175、剩 3 名額）— 先做樣稿 20 多分鐘，回來案件已「無法查看」，沒報到
- 現成樣稿可重複用：`~/Desktop/接案/許小姐_攝影作品集網站/`（作品集網站）、`~/Desktop/接案/顏小姐_日系選品網站/`（購物網站），改名字就能先附上，不用每次重做

## 🚫 資訊空白的新案先用保證回覆（2026-10-12 教練拍板）
- 案主**發案紀錄 0 次＋沒有描述＋沒寫預算** → 一律用「保證回覆」，對方真的回覆才扣錢
- 實例：許〇傑（台中豐原・影片劇本），一般 160 送出、拿到電話，打過去對方說「我是要接案的」＝專家誤用發案身分，假需求
- 處理：工作訊息 → 右上「• • •」→ 回報問題 → 可疑案件 → 不實刊登，寫明時間、金額、對方原話，申請退聯繫費（2026-10-12 已送）
- 同一位客戶換類別重發（例：邱〇緯從「紀錄片」改發「影片剪輯」）→ 已有電話或 LINE 就不要再付一次

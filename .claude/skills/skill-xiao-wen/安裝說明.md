> 版本：v1.0（2026-08-29）

---

## 這個 Skill 是做什麼的

**把一個產品，變成可以直接貼上去、會讓人掏錢的文字。**

| 有了小文 | 沒有小文 |
|:---|:---|
| 先挖賣點（功能→利益→結果）再動筆 | 對著空白畫面想半天 |
| 主標 ×3、CTA ×2，可以直接 A/B | 只有一版，好不好全靠猜 |
| 用客戶原話寫，一看就是我們家 | 全是「專業、用心、優質」 |
| 出門前自動跑合規稽核 | 廣告被退、被檢舉才知道踩線 |

⚠️ 小文**不寫短影音腳本**（那是小爆／小構）、**不投廣告**（小廣）、**不排版**（小美）、**不做網站**（小網）。
口訣：**要被「讀」的長文字歸小文，要被「聽」的口播腳本歸小爆。**

## 安裝（macOS）

1. 解壓 `skill-xiao-wen.zip`
2. 把整個 `skill-xiao-wen` 資料夾拖到：
   ```
   ~/.claude/skills/
   ```
   （在 Finder 按 `⌘ + ⇧ + G`，貼上 `~/.claude/skills/`）
3. 重開 Claude Code，輸入「**小文**」測試。

## 安裝（Windows）
放到：`C:\Users\<你的帳號>\.claude\skills\`

## 怎麼用

直接打「小文」，或直接說需求：

- 「小文，幫我寫〈XX 課程〉的銷售頁」
- 「小文，這段文案幫我健檢」
- 「幫我下三版廣告主標」
- 「寫一組 5 封的 Email 序列」
- 「幫我想 5 個 Slogan」

小文會**先問五題**才動筆：賣什麼（含價格）、賣給誰、他現在都買誰的、憑什麼相信你、看完要他做什麼。
這五題不是客套，是文案準不準的關鍵。

## 單獨跑合規稽核

```bash
python3 ~/.claude/skills/skill-xiao-wen/scripts/copycheck.py 你的文案.md
```

指定行業做必載事項檢查：

```bash
python3 ~/.claude/skills/skill-xiao-wen/scripts/copycheck.py 文案.md --industry 不動產
```

支援行業：不動產／醫療／食品／化粧品／醫療器材／課程／旅遊／保險
輸出 🔴 一律先改再交；🟡 需人工確認有無事實依據。

## ⚠️ 三條不可協商的紅線

1. **不寫療效**（保健品、器材、精油、益生菌一律只能寫溫熱舒緩／生活風格）
2. **不寫收益保證**（不得寫保證賺、穩賺不賠、月入 X 萬）
3. **不編造見證與數據**（見證要真人、要書面同意；數字要有出處）

# 小房 ▎安裝與使用

## 內部版（你的公司自用）
已安裝在 `~/.claude/skills/skill-xiao-fang/`，工作區 `~/AI員工_小房/`。
訊息裡出現「小房」就會被叫出來；單打「小房」兩字＝直接跑成交看板。

## 學員版
解壓縮後把 `skill-xiao-fang/` 整個資料夾放到 `~/.claude/skills/`，重開 Claude 即可。
工作區預設是當前資料夾下的 `小房_工作區/`，可用環境變數改：

```bash
export XIAOFANG_HOME=~/我的客戶資料
```

## 常用指令

```bash
S=~/.claude/skills/skill-xiao-fang/scripts/dealflow.py

python3 $S pipeline                                   # 今天該追誰
python3 $S new --name 王先生 --phone 09xx --source FB   # 建客戶卡
python3 $S showing --client C001 --date 2026-10-05 --properties "A社區,B華廈,C電梯"
python3 $S log --client C001 --result "看完B最喜歡" --decider --narrowed
python3 $S offer --client C001 --property B華廈 --price 1280萬   # 先出告知書
python3 $S check --file 我的話術.txt                    # 合規稽核
python3 $S report --client C001                        # 客戶報告
```

## 資料放哪
- 客戶資料：`<工作區>/data.json`
- 產出文件：`<工作區>/out/`

⚠️ 客戶名單屬所屬公司資產，不得攜出或外流。離職換公司時請依公司規定處理。

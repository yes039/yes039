# 小房 ▎客戶分級與追蹤節奏

## 分級標準（四個條件，符合幾個就是幾分）

| 條件 | 說明 |
|---|---|
| **決策者到位** | 會一起做決定的人都已經參與過 |
| **資金明確** | 自備款金額講得出來，貸款條件問過銀行 |
| **時間明確** | 說得出要在幾月前入住，而且有原因 |
| **條件收斂** | 經過 2 次以上帶看，條件有調整、有排序 |

- **A 級（4 分）**：週追 2 次。隨時可能成交，有新物件第一個給他。
- **B 級（2–3 分）**：週追 1 次。目標是把缺的那一項補起來。
- **C 級（0–1 分）**：月追 1 次。放長線，不排帶看，不浪費看屋成本。

分級**每次帶看後重算**，不是一開始定了就不動。`dealflow.py log` 會自動重算。

---

## 追蹤內容：不要問「考慮得怎麼樣」

每次追蹤都要帶一個**對他有用的新東西**：

| 情境 | 追蹤內容 |
|---|---|
| 他擔心車位 | 量好尺寸、拍進出影片 |
| 他擔心漏水 | 問到屋主上次防水施作年份與保固 |
| 他擔心學區 | 查教育局當年度公告並附連結與日期 |
| 他擔心貸款 | 轉介銀行專員（先取得他同意再給聯絡方式） |
| 真的沒有新東西 | 給本區最新成交資料，說明市場在動 |

**沒有新東西就不要打電話。** 空洞的「考慮得怎麼樣」會把客戶推遠。

---

## 逾期判定

- A 級超過 **4 天**沒聯絡 → 逾期
- B 級超過 **10 天**沒聯絡 → 逾期
- C 級超過 **35 天**沒聯絡 → 逾期

`dealflow.py pipeline` 每天會把逾期的列在最上面。

---

## 什麼時候該放掉

符合兩項以上就降 C 或結案，把時間還給自己：

- 連續 3 次約看都臨時取消
- 要求的條件在市場上不存在（預算與條件差距超過 30%）
- 決策者始終不出面，而且不說明原因
- 明確表示同時委託 3 家以上且不願意給任何承諾
- 要求做違規的事（假收入證明、幫忙規避實價登錄、要求回扣）

最後一項**不是降級，是立刻結案並記錄**。

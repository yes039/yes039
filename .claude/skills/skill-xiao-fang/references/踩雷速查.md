# 小房 ▎踩雷速查

| 症狀 | 真正的原因 | 怎麼處理 |
|---|---|---|
| 帶看很多次都不下斡 | 決策者沒出現 | 回到需求確認，問「誰會一起決定」 |
| 客戶每次都說「再看看」 | 沒有明確障礙 | 逼出三選一：價格／屋況／家人 |
| 開價談不下來 | 買賣方各看各的資料 | 改用同一份實價登錄與可比物件表 |
| 下斡後賣方反悔 | 委託條件沒確認清楚 | 收斡前先確認屋主底價與授權範圍 |
| 簽約前才發現貸款不足 | 沒有先確認財力 | 需求階段就問自備款，出價時寫入特約 |
| 客戶抱怨服務費 | 事前沒寫清楚 | 收費標準與比率事先寫進契約並當面說明 |
| 交屋後客訴漏水 | 說明書寫「無」 | 不確定一律寫「待查證」，不寫「無」 |
| 客戶要求做假文件 | —— | 立刻拒絕、書面記錄、告知店長，案件結案 |

## 三個最常見的致命錯誤

**1　先收斡旋金，再補告知書**
順序顛倒就是違規。`dealflow.py offer` 會擋。

**2　說「保證」兩個字**
保證增值、保證投報、保證貸款成數、保證租得掉——說出口就有責任。
`dealflow.py check` 會掃，但真正的防線是你自己的嘴。

**3　口頭承諾沒留書面**
「我記得你說過」是九成糾紛的起點。當天用訊息把口頭內容寫一次給客戶確認。

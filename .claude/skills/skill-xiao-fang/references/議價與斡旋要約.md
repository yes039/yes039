# 小房 ▎議價、斡旋與要約

## 一、議價的結構

議價不是喊價來回，是**把雙方的理由對齊到同一份資料**。

| 對象 | 他真正要的 | 你要給的 |
|---|---|---|
| 買方 | 「我沒買貴」的證據 | 同社區／同類型近期實價登錄區間、可比物件條件差異表 |
| 賣方 | 「我沒賣便宜」的台階 | 同社區近期成交、目前銷售天數、看屋組數與回饋 |

兩邊用**同一份資料**，差距會收斂；各講各的版本，必定卡死。

**三個不要**
- 不要替賣方喊「屋主說最低就這樣」——把你變成傳聲筒，你就沒有價值。
- 不要替買方猜「他應該可以再加」——沒簽的加價都不算數。
- 不要用「今天不下就沒了」製造假稀缺，這是欺罔。

**抓真實上限的問法**（問買方）
> 「如果今天這間是 X 萬，你會不會買？」
> 「那 X 減 50 萬呢？」
> 不是為了砍價，是為了找出那個「會」與「不會」的交界。

## 二、斡旋金 vs 要約書

|  | 斡旋金 | 要約書（內政部版） |
|---|---|---|
| 要不要先付錢 | 要，交付一筆金額 | **不用付錢** |
| 性質 | 以金錢表示購買誠意 | 以書面表示購買意思 |
| 賣方同意後 | 斡旋金通常轉為定金 | 契約成立，再付定金 |
| 買方反悔 | 可能被沒收 | 仍須負違約責任（不是沒有責任） |
| 常見誤解 | — | 「要約書沒拘束力」是**錯的** |

🚨 **要約書不是沒有責任的版本**。賣方承諾後買方反悔，一樣要負違約責任。
跟客戶說明時不要暗示「要約書比較沒風險」，那是誤導。

## 三、強制順序（違反就是違規）

```
① 《出價前二擇一告知書》 → 客戶簽名勾選他要用哪一種
② 告知定型化契約審閱期至少 3 日
③ 才進入斡旋金收據或要約書
④ 真人逐項確認：價格／有效期限／付款方式／交屋日／特約條件
⑤ 真人送出
```

跑 `dealflow.py offer` 會從 ① 開始，不要自己跳到 ③。
法源與理由見 `合規紅線.md` 紅線一、紅線三。

## 四、出價單上一定要寫清楚的五件事

1. **價格**（含是否含車位、是否含稅費分擔）
2. **有效期限**（到期未承諾即失效，避免無限期綁住）
3. **付款方式與各期時點**
4. **交屋日**
5. **特約條件**——最常被漏掉的是：
   - 貸款不足額時的處理（補足？解約？解約是否無條件退還）
   - 現況交屋或整理後交屋
   - 既有租約是否承接
   - 漏水、壁癌等瑕疵的處理期限

特約沒寫清楚，後面全部變糾紛。

## 五、客戶常見問題的標準回答

**「斡旋金會不會被吃掉？」**
> 賣方還沒同意前，你可以撤回，斡旋金應該退還。賣方同意之後就成為定金，這時反悔才有沒收問題。
> 你也可以選擇不付斡旋金、改用內政部版要約書，兩種我都會給你書面說明。

**「服務費是不是固定 2% 和 4%？」**
> 那是業界常見作法，不是法定比率。法定是買賣雙方**合計**不超過成交價 6%。
> 我們公司的收費標準是…，會事先寫在契約裡給你確認。

**「可以先口頭談好，文件後補嗎？」**
> 不行。口頭的部分我會當天用訊息寫給你確認，但正式出價一定要書面，這是保護你也保護我。

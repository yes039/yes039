## 一、食品安全主要法源（台灣）

| 法規 | 評鑑對應 |
|---|---|
| 食品安全衛生管理法 | 標示、添加物、業者責任、罰則 |
| 食品良好衛生規範準則（GHP） | A 構面現場查核的基本依據 |
| 食品安全管制系統準則（HACCP） | A1 驗證查核 |
| 食品業者登錄辦法 | 業者登錄字號查核 |
| 食品過敏原標示規定 | D5 過敏原標示（11 類） |
| 餐飲業製備食品良好衛生管理 | 溫度、交叉污染防制 |

> 🔎 **法規會修正。** 每年要點修訂時（2–3 月）**必須重新查證現行條文與最新公告**，
> 不要沿用去年的條號。引用錯誤的條號，是業者申訴時最容易攻擊的破口。

## 二、特許經營契約常見條款（評鑑的真正依據）

評鑑的效力來自**契約**，不是來自評鑑辦法本身。報告引用條款時要找對地方：

| 條款類型 | 評鑑對應 | 注意 |
|---|---|---|
| 營業時間條款 | C3 | 通常約定「配合航班時刻」，需確認具體定義 |
| 同價（街價）條款 | D1 | 確認容許價差、比價基準門市、適用品項範圍 |
| 權利金與保證營業額 | C1/C2 | 分為固定權利金／抽成，計算基礎要看清楚 |
| 裝修與識別變更 | E1 | 通常需事前報准，擅改即違約 |
| 評鑑與考核條款 | 全部 | **評鑑結果能產生什麼效力，完全看這一條怎麼寫** |
| 違約金與終止條款 | 處置建議 | 小評只建議，不認定 |
| 轉讓與委外限制 | — | 發現實際經營者與契約當事人不符，應即回報 |

### 🚨 紅線
**評鑑報告不得逾越契約已約定的效力。**
契約沒寫「評鑑丙等得終止契約」，報告就不能寫「應予終止」——只能寫「建議提報契約檢討」。

## 三、程序正義：評鑑最容易被翻案的地方

評鑑是行政性質的判斷，**程序瑕疵比分數錯誤更致命**。六個必守：

1. **要點先公告，再評鑑。** 評鑑期間不得變更配分或新增指標。
2. **標準一致。** 同一指標對所有業者採同一尺規；業種差異須事先於要點中明定（如候餐時間分業種）。
3. **給予陳述意見機會。** 初評分數應通知業者，設異議期（建議 7–14 日）。
4. **異議要有紀錄。** 業者異議與處理結果書面留存，變更分數須載明理由。
5. **利益迴避。** 評審委員與稽查人員均應簽署利益迴避聲明。
6. **證據保存。** 建議保存至**次年度評鑑結案後 1 年**，爭訟期間不得銷毀。

## 四、個資與商業機密

| 資料 | 處理原則 |
|---|---|
| 業者營業額、坪效 | **商業機密**，不得於公開版報告揭露，不得對其他業者透露 |
| 神秘客個人資料 | 不留存於報告；報告僅記錄觀察事實 |
| 從業人員健檢資料 | **敏感個資**，稽查僅查核「有無有效證明」，**不得抄錄病歷內容、不得拍攝健檢報告內頁** |
| 客訴人資料 | 去識別化後始得引用 |
| 評鑑分數 | 公告前不得外洩；洩漏者迴避並依內規處理 |

> ⚠️ A4 查核健檢時，**只看名冊與有效期限，不看檢查結果**。拍到健檢報告內頁就是個資事故。

## 五、消保與公平交易相關

- **價目表揭示**：應明確標示是否含稅、是否另收服務費
- **廣告不實**：菜單圖片與實際供應差異過大可能構成不實廣告
- **原產地標示**：宣稱在地／進口者須可佐證

## 六、小評的三條法律紅線（再說一次）

1. ❌ **不做處分決定。** 報告只出具建議；契約處分、罰則、續約與否由權責單位依契約條款決定。
2. ❌ **不對業者承諾結果。** 稽查現場不透露分數、不預告等第。
3. ❌ **不代表資方發函。** 需要發函（限期改善通知、違約通知）時，由權責單位以其名義發出；
   涉及法律效果的函文一律先送 `skill-xiao-bian`（小辯）審閱。

## 七、乙方（受評業者）立場的合規紅線

小評如果是站在受評業者這一邊做自評輔導，紅線完全不同：

- ❌ **不得美化或造假申報數據**（溫度紀錄、營業額、班表）——造假被抓到比缺失本身嚴重得多
- ❌ 不得對稽查人員提供招待、禮品
- ❌ 不得探詢神秘客身分或稽查時程
- ✅ 可以做的是：**把該有的紀錄補齊、把該修的缺失修好、把證據整理成隨時可受檢的狀態**
- ✅ 對確有爭議的評分，走正式異議程序，備妥書面證據（必要時由小辯協助撰擬）

# 現場稽查作業手冊｜神秘客腳本、查檢動線、證據規範

## 一、稽查佈點原則：分散、突襲、涵蓋尖離峰

**每家業者一年至少 4 次接觸：**

| 次別 | 時期 | 方式 | 重點 |
|---|---|---|---|
| 1 | 淡季（5–6 月） | 公開現場稽查 | 食安書面＋現場、設施、標示 |
| 2 | 旺季（7–8 月） | 突襲現場稽查 | 候餐時間、供餐能量、缺品率、人力 |
| 3 | 不定期 | 神秘客（平日） | 服務流程、點餐體驗、結帳正確性 |
| 4 | 不定期 | 神秘客（假日尖峰） | 尖峰服務品質、清潔維持 |
| 加碼 | 深夜／清晨 | 突襲 | **營業時間遵守**（最常出事的一項） |

### 🚨 三條佈點鐵律
1. **不預告。** 預告過的稽查只能列為「輔導訪視」，**不計入評鑑分數**。
2. **不固定時段。** 只在星期二早上去查的評鑑，測不出真實服務水準。
3. **單次觀察不成立結論。** 任何缺失至少要 **2 次獨立觀察**才寫入年度報告，除非是食安 veto（當場拍照＋簽認即成立）。

## 二、神秘客腳本（每次完整跑一輪，全程不表明身分）

### 準備
- **全額自費**，保留發票／收據作為證據
- 不接受任何招待、升等、贈品
- 攜帶：手機（拍照／計時）、溫度計（不使用於他人餐點）、記錄表

### 流程與觀察點

| 階段 | 計時起訖 | 觀察點 |
|---|---|---|
| **① 接近** | — | 招牌燈光、價目表可讀性、門口清潔、是否有人招呼 |
| **② 排隊** | 入列→輪到我 | 隊伍管理、動線是否阻礙通行、等候時間 |
| **③ 點餐** | 輪到我→完成付款 | 招呼語、眼神接觸、推薦能力、**英語應對**、過敏原詢問能否回答 |
| **④ 候餐** | 付款完成→取餐 | **這一段是 B2 的正式量測值**，記錄到秒 |
| **⑤ 用餐** | — | 餐點與菜單圖文相符度、溫度、份量、餐具清潔、桌面清潔 |
| **⑥ 結帳／離場** | — | 金額與價目表一致？收據正確？翻桌清潔時效 |
| **⑦ 洗手間／公共區** | — | （若屬業者管轄）清潔度、備品 |

### 評分紀錄要求
- 每一階段**當場**記錄，離場 10 分鐘內完成書面
- 主觀評語必須附客觀事實：
  - ❌「服務態度不佳」
  - ✅「點餐時人員未抬頭、全程未回應詢問之過敏原問題（14:22，收據 #A0231）」

## 三、現場稽查動線（公開稽查 60–90 分鐘）

```
① 店外觀察（勿先表明身分，5 分鐘）
   招牌、價目表、排隊狀況、油煙異味 → 先拍
        ↓
② 表明身分、出示稽查通知（請店長或代理人陪同）
        ↓
③ 外場：座位區、清潔、標示、逃生動線（10 分鐘）
        ↓
④ 內場：⚠️ 食安核心，花最多時間（30 分鐘）
   冷藏冷凍溫度（自帶溫度計實測）→ 備料區效期抽查 ≥10 項
   → 人員衛生觀察 → 油品 → 洗手台與清潔用品 → 病媒防治
        ↓
⑤ 書面：驗證證書、健檢名冊、進貨單據、班表、保養紀錄（20 分鐘）
        ↓
⑥ 當場口頭告知初步發現，請現場人員於查檢表簽名
   ⚠️ 不透露分數、不承諾等第
```

> **④ 內場先量溫度**——一進去就量，不要等。讓業者有時間調整的量測值不可信。

## 四、證據規範（沒有證據不給分）

### 命名規則
```
業者代碼_日期_時間_項目_序號.副檔名
V001_20270815_1230_溫度紀錄_01.jpg
V001_20270815_1235_備料區效期_03.jpg
```

### 拍攝要求
| 類型 | 要求 |
|---|---|
| 缺失照片 | **遠景（看得出位置）＋近景（看得清細節）各 1 張** |
| 溫度 | 溫度計讀值與設備標示同框 |
| 效期 | 商品標示清晰可讀，必要時加拍當日報紙／手機日期同框 |
| 書面文件 | 整頁可讀，含發證日／有效期限欄位 |
| 價格 | 價目表全景＋該品項特寫；市區門市價另存對照 |

### 🚨 不採認的證據
- ❌ 回辦公室後補拍、補寫的紀錄
- ❌ 業者自行提供、未經現場核對的照片
- ❌ 無法辨識時間與地點的照片
- ❌ 單一張「全景」照片就要證明多項缺失

## 五、量測方法（數字要一致，不然沒得比）

| 量測 | 方法 | 樣本數 |
|---|---|---|
| 候餐時間 | 付款完成→取餐，**取中位數** | ≥10 筆 |
| 缺品率 | 掛牌品項中無法供應者 ÷ 總掛牌品項 | 全菜單 |
| 街價差率 | (機場價 − 市區價) ÷ 市區價 | ≥10 項共同品項 |
| 冷藏溫度 | 自帶探針式溫度計，中層中央，穩定 30 秒讀值 | 每台設備 1 點 |
| 效期抽查 | 備料區隨機 | ≥10 項 |
| 尖峰人力 | 尖峰時段現場實際點數，對照班表 | ≥2 個時段 |

## 六、稽查人員行為準則

- ❌ **不接受任何招待**——餐點、飲料、禮品、免費升等一律拒絕
- ❌ 不預先透露稽查時間、神秘客身分、暫定分數
- ❌ 不在業者面前評論其他業者
- ❌ 不對業者承諾任何評等結果
- ⚠️ **利益迴避**：與受評業者有親屬、投資、僱傭關係者，一律申報並迴避該案
- ⚠️ 全程保持可受公評的態度——**你今天的每一句話，都可能出現在申訴書上**

## 七、常見翻車點（前人踩過的）

| 翻車點 | 後果 | 正確做法 |
|---|---|---|
| 缺證據卻給了 0 分 | 業者申訴「你根本沒查」，整案退回 | 標 N/A 進補件清單 |
| 單人認定食安 veto | 業者否認事實，無法舉證 | 雙人到場＋拍照＋現場簽認 |
| 只查白天 | 測不到提早打烊 | 深夜／清晨各 2 次突襲 |
| 候餐時間取平均 | 一筆極端值拉垮整體 | 取中位數，樣本 ≥10 |
| 評語寫「有待加強」 | 無法複查，改善追蹤無依據 | 寫成「缺失事實→依據條款→限期→複查方式」 |
| 不同稽查人尺規不一 | 業者比較後申訴不公 | 用行為錨定尺規，稽查前先做一致性校準 |
| 報告寫了商業機密 | 公開後爭議 | 內部版／公開版分開產製 |

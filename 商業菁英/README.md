## 編輯規範

1. **封面一致**：比照 No.001 的海報版式（941×1672）：刊頭、封面人物、本期焦點四格、底部紅色導覽列。人物在最前面，文字不可壓到人物。
2. **內外一致**：封面、網頁標題、內頁頁首、PDF、LINE 分享文案要同步更新期別與日期。
3. **可編輯文字**：刊號、日期、主題等會變動的資訊做成網頁文字，不燒進圖片（No.002 起實施）。
4. **不談功效**：只描述原料、風味與文化，不寫療效或保健功效。
5. **查證標示**：資料區分「已查證事實／編輯分析／尚待確認」，引述刊登前由受訪者確認。
6. **出版流程**：前置調查 → 編輯企劃 → 經確認後才進入封面設計、排版與正式出版。
7. **分享文案**：不用表情符號，改用 ✦、▸ 等純文字符號；先傳封面圖，再貼文案。
8. **利益揭露**：受訪者、商品或服務與《商業菁英》有合作關係時，文末標明「合作關係說明」。
9. **狀態分級**：經營事項分為「已完成／改善中／未來規劃」，不得把推論寫成事實。
10. **衍生授權**：採訪前一次取得受訪者同意，涵蓋電子報、方格子、FB、LINE 與短影音。
11. **AI 實戰筆記**：每期一個小單元，說明這個案例可以怎麼用 AI；沒有自然的應用就不硬湊。

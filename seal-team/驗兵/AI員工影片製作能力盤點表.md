## 三、結論：選誰跟 C 獨立製片做同題比較？

**符合「能自己出片」條件的只有小曲，但它不是理想的比較對象。** 能拿來比較的現有員工，只剩它一位。

| 候選 | 能比嗎 | 原因 |
|---|---|---|
| **小曲** | **可以，有條件** | 唯一做過 MP4 的員工。限制：①題目必須是它的格式「照片＋AI 歌曲的 MV」，不是一般宣傳短片 ②每支約 1,376 點 ElevenLabs ③只能內部測試，授權未確認，結果不能直接變成商品 ④M003 已經顯示原版需要 C 補強 |
| 製片兵 | 不合格 | 自己不出片，比較的實際上是「Shen 在 CapCut 組片」vs「C 出片」 |
| 小講 | 不合格 | 只做倒數計時畫面，不是素材短影音 |
| 小廣 | 不合格 | 出片要靠一個不在包內的 skill 和 HeyGen |
| `video-shotcraft` | **未知** | 名稱看起來和影片有關，但還沒盤點 |

**如果比較的目的是「一般小店宣傳短片」**（例如宜大鐵板燒、夯 Bar 這種）：**現有員工中沒有合格對象。** 這類影片目前只有 C 直接做過。

**做決定前建議先確認一件事**：`video-shotcraft` 是什麼。它已經裝在你的 Mac 上，可能是一個影片 skill。只需要讀它的 SKILL.md，不用執行；如果它真的能用素材出片，它可能比小曲更適合當比較對象。

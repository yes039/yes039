## 演習驗收標準（跑通 = 全部打勾）
- [ ] 三份文件編號一致（M001-V1 / M001-T1），下游沒有自己補上游資料
- [ ] 製片兵若遇素材不足，有停工回報而非自行假設
- [ ] 偏差紀錄有填（即使是「無偏差」）
- [ ] 戰果單每個數字都能對到截圖
- [ ] 戰果庫有第一列
- [ ] 復盤寫出「流程卡點」至少 1 條（這是回煉的原料）

## 復盤模板（`04-復盤/復盤.md`）

```
# M001 復盤

## 是否觸發換器條件（依武器配置表）

```

## 首戰建議（企劃兵可參考，非強制）
- 商業目標選「來店」，CTA 用通關密語 → 線下計次最容易、最不需要平台數據。
- 片長 15–25 秒，一支片、一個平台先跑通；多平台是擴編。
- 首戰測試點建議選「基準建立」：本片數據即為後續對照基準，判讀規則只看是否達最低門檻。

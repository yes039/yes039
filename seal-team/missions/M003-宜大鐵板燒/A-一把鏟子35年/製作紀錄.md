## 4. 製作方式

全部在本機完成，沒有使用外部素材，也沒有使用 AI 生成畫面。
- 畫面：`source/render.py`，用 Python／PIL 逐格合成，加上照片推拉搖、暖色調、暗角、底片顆粒，字幕後方有柔和的壓暗帶
- 配樂：`source/music.py` 寫 MIDI（F 大調，鋼琴＋弦樂），用 FluidSynth＋FluidR3 GM 音色渲染
- 混音：`source/mix.py`，最後統一響度到約 -14 LUFS
- 封面：`source/cover.py`

重新產出：

```bash
apt-get install -y ffmpeg fonts-noto-cjk fluidsynth fluid-soundfont-gm && pip install scipy mido
cd source
python3 render.py <repo根目錄> <工作資料夾>
python3 music.py <工作資料夾>/music.mid
fluidsynth -ni -g 0.6 -r 44100 -F <工作資料夾>/music_raw.wav /usr/share/sounds/sf2/FluidR3_GM.sf2 <工作資料夾>/music.mid
python3 mix.py <repo根目錄> <工作資料夾>
ffmpeg -framerate 30 -i <工作資料夾>/frames/f%04d.jpg -i <工作資料夾>/final_audio.wav -c:v libx264 -preset slow -crf 23 \
  -pix_fmt yuv420p -af loudnorm=I=-14:TP=-1.5:LRA=11 -ar 48000 -c:a aac -b:a 192k -t 34.6 out.mp4
```

## 5. 發布前要確認的事（Shen）

1. **客人入鏡**：S6（26–29.6 秒）店內照片裡有客人，看得出臉。如果沒有取得同意，我可以把臉模糊掉，或換成沒有客人的鏡頭。
2. **現場原音沒有經過人工試聽**：我只能量音量，聽不到內容。如果原音裡有客人說話，聽了不舒服的話告訴我，我換成其他段落。
3. **地址、營業時間**：說明文字裡留了空位，需要店家提供。
4. **鏟子牆的由來**：如果店家能證實這些鏟子確實是每個時期實際用過、用舊了才換下來，文案可以寫得更有力，例如「用到換，才掛上牆」。目前沒有依據，所以沒寫。

## 6. 跟原訂片名的差異

原訂片名是「一把鏟子，35 年」，但素材顯示牆上是**十把**鏟子，每把各代表一段年份，不是一把鏟子用了 35 年。照字面寫會跟畫面矛盾，所以片中與封面改用「這面牆上，掛著 35 年」。內部檔名維持「A-一把鏟子35年」，方便對照。

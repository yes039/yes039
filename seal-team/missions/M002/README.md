# M002｜「60+ 學 AI」30 秒招生短影片（9:16）

- 成片：[02-製作/60plus學AI-招生-30s-9x16.mp4](02-製作/60plus學AI-招生-30s-9x16.mp4)（1080×1920、30fps、H.264＋AAC、-14 LUFS）
- 字幕檔：[02-製作/字幕.srt](02-製作/字幕.srt)（字幕已燒進成片，這份 .srt 給平台另外上傳時使用）
- 封面：[02-製作/封面.jpg](02-製作/封面.jpg)

對象：60 歲以上、還不熟悉 AI 的人。
核心感受：「原來 AI 沒那麼難，我也做得到。」

## 故事線（情緒：困惑 → 安心 → 好奇 → 驚喜 → 驕傲）

| 時間 | 畫面 | 旁白／字幕 | 情緒 |
|---|---|---|---|
| 0.0–2.5 | 早晨廚房，阿嬤手機震動，皺眉歪頭 | AI？聽起來好難， | 困惑（冷色調） |
| 2.5–4.8 | 手機特寫：孫子傳「妳可以用 AI 幫我寫祝福啊！」，她打字「AI？那是什麼…我不會啦」又刪掉 | 好像跟我沒關係…… | 退縮 |
| 4.8–9.6 | 社區教室，老師靠過來耐心教，阿嬤從緊張到抬頭微笑、點頭 | 其實，AI 就像一個很有耐心的朋友 | 安心（轉暖色） |
| 9.6–14.4 | 手機特寫：按住麥克風說「幫我寫一段生日祝福給孫子」，AI 逐字寫出祝福 | 不用打字，按著說話就好 | 好奇 |
| 14.4–16.1 | 公園，舉起手機拍扶桑花（快門閃光） | 拍張照片， | 投入 |
| 16.1–18.1 | 手機特寫：AI 回答「這是扶桑花🌺…」 | 它也看得懂 | 期待 |
| 18.1–19.2 | 阿嬤臉部特寫：挑眉「哇」→ 笑開 | — | 驚喜 |
| 19.2–24.0 | 傍晚沙發，和戴生日帽的孫子視訊，孫子：「阿嬤好厲害！👍」，愛心飄起 | 原來 AI 沒那麼難，我也做得到！ | 驕傲（音樂最高點） |
| 24.0–30.0 | 同學與老師合照、比讚，下方報名卡滑入：「60+ 學 AI／小班慢慢教・一步一步陪你學會／立即報名」 | 60+ 學 AI，小班慢慢教。現在就來報名！ | 行動 |

「按住說話、拍照問問題、請它幫忙寫字」三個實際用法都有出現在畫面裡，也寫在教室白板上。

## 製作方式（全部在本機完成，沒有使用外部素材）

| 項目 | 做法 |
|---|---|
| 畫面 | SVG／JS 逐格繪製的插畫風動畫（人物表情、眨眼、手持鏡頭晃動、景深模糊、底片顆粒、暗角），用 Playwright＋Chromium 輸出 900 格 |
| 旁白 | 離線中文 TTS（zhtts／FastSpeech2＋MB-MelGAN，標貝女聲），語速放慢約 8% |
| 音樂 | 程式寫的 MIDI（100 BPM，每 2 小節一個剪輯點；開場鋼琴 → 加入弦樂／撥弦 → 驚喜段加鐘琴旋律與輕鼓），用 FluidSynth＋FluidR3 GM 音色渲染 |
| 音效 | numpy 合成：震動、訊息提示音、打字聲、按鈕聲、送出聲、快門、轉場 whoosh |
| 混音 | 旁白出現時音樂自動壓低約 55%，最後統一響度 -14 LUFS |
| 剪輯 | 9 個鏡頭，切點對齊音樂小節；困惑→安心、驚喜→驕傲兩處用溶接 |

原始碼在 [02-製作/source/](02-製作/source/)。

### 重新產出

```bash
apt-get install -y ffmpeg fonts-noto-cjk fluidsynth fluid-soundfont-gm
pip install "tensorflow-cpu==2.15.1" pypinyin scipy mido
pip download zhtts --no-deps && unzip zhtts-0.0.1-py3-none-any.whl -d ../tts/zh   # vo.py 會從 ../tts/zh 載入
python3 vo.py            # 產生 vo0–vo5.wav 與 vo_dur.json
python3 music.py && fluidsynth -ni -g 0.7 -r 44100 -F music_raw.wav /usr/share/sounds/sf2/FluidR3_GM.sf2 music.mid
python3 mix.py           # 產生 final_audio.wav
NODE_PATH=$(npm root -g) node render.js frames 0 900
ffmpeg -framerate 30 -i frames/f%04d.jpg -i final_audio.wav -c:v libx264 -crf 21 -pix_fmt yuv420p \
  -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:a aac -b:a 192k -t 30 out.mp4
```

## 已知限制／發布前要補的

- **不是真人實拍。** 這個製作環境連不到圖庫與 AI 影片生成服務，所以「真人感」是用有表情、有生活場景的插畫動畫來做。若要真人版，分鏡表可以直接拿去實拍或丟給影片生成工具。
- **旁白是 TTS 女聲**，音色偏年輕。建議換成真人配音（最好是長輩或溫暖的中年聲音），聲音檔換掉 `vo0–vo5.wav` 後重跑 `mix.py` 就好。
- **報名資訊還沒放。** 報名卡只寫「立即報名」，沒有電話、網址、QR code、時間、地點或價格。請提供後加進 `scenes.js` 的 `S6`，或上傳平台時寫在貼文文字裡。
- 畫面中的「AI 小幫手」是虛構的通用 App 介面，沒有指涉特定品牌。

# FB／IG 廣告文案（宜大鐵板燒）

【】內為待店家確認，上線前要替換。

## 廣告設定建議

| 項目 | 建議 |
|---|---|
| 廣告目標 | 互動（訊息）或流量（導到 Google 地圖／LINE）；有訂位系統用「流量」 |
| 版位 | Reels＋限時動態＋動態消息（用 9:16 一支片；動態消息會自動裁成 4:5，重要字放畫面中間） |
| 受眾 | 店家方圓 3–5 公里、20–55 歲；興趣：美食、餐廳、鐵板燒、宵夜 |
| 預算 | 先每天 NT$300–500 跑 3 天看數據，再決定加碼哪一版 |
| 影片規格 | 1080×1920、MP4、15 秒（A）／30 秒（B）、上傳 `.srt` 或字幕燒進畫面 |

## 上線前提醒
- 影片裡的菜色都要是**店裡真的有賣、長得一樣**的。即夢生成片段如果讓食物「變更好看」，那支不要用。
- 「35 年」= 2026 − 1991，若店家習慣說「30 多年」就照店家說法。
- 師傅入鏡要先口頭同意用在付費廣告。

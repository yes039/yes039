## 我怎麼判斷這支片

受眾本來就會用手機，所以**開場先肯定他**（「手機，你早就很會用了」），再丟出真正的卡點（「那 AI 呢？跟我有什麼關係？」）。
整支片不找年輕人來教、也不演「不會用」，只演**同齡人自己玩、自己做出東西、自己分享**。

情緒線：被說中 → 看到用法 → 覺得不難 → 想分享 → 「欸，我自己真的會了」 → 知道去哪裡上

| 時間 | 素材 | 畫面上的字 | 要讓觀眾想到 |
|---|---|---|---|
| 0.0–4.8 | A01 獨自看手機 | 手機，你早就很會用了／**那 AI 呢？**／聽過很多次，但跟我有什麼關係？ | 「這在說我。」（Hook） |
| 4.8–12.0 | A05 拍一桌菜＋示意對話畫面 | 拍下今天煮的菜 → 🎤 不用打字，用說的就好 → 說「幫我把今天煮的菜，寫成一段臉書分享」→ AI 一句句寫出分享文 → **一段生活分享，就寫好了！** | 「原來跟我的生活有關」「用說的就好，不難」 |
| 12.0–16.8 | A06 山上旅行自拍 | 還能這樣玩：旅行照片→寫成遊記／老照片→說出家的故事／腦袋裡的想法→幫你整理成文字 → **好像⋯沒有想像中那麼難耶！** | 「這些我真的用得到」「好像滿好玩的」 |
| 16.8–19.2 | A03（照片本身就有「你也會用 AI 了？」） | 自己做的，**傳給朋友看** | 「朋友會對我刮目相看」 |
| 19.2–22.8 | A02 一群朋友驚呼 | 欸，**我自己真的會了！**／學會了，還能教朋友一起玩 | 最後那個小小的成就感（音樂最高點） |
| 22.8–25.2 | A07 課堂大家一起操作 | 不是坐著聽課，是**自己動手玩一次** | 「這堂課長這樣，我去了也是自己動手」 |
| 25.2–30.0 | 片尾卡（課堂照模糊當底） | 給 60+ 的你／**AI 生活體驗課**／不是電腦課・是親手操作／第一次把 AI 用進生活／**費用 500 元**／上課時間・地點・報名方式請看貼文說明 ↓ | 知道這是什麼課、多少錢、去哪看報名 |

取捨：
- 7 個已知場景只**演一個**（拍菜→用說的→寫成臉書分享），因為它一次涵蓋「不用打字」「寫生活分享」「拍美食」三件事，而且素材剛好有；旅行／老照片／整理想法用一排小卡帶過，不各自展開，30 秒才講得完。
- v2 用旅行照（A06）墊在「旅行照片→寫成遊記」小卡後面，畫面和字講的是同一件事；A04（咖啡廳三人）因此拿掉。
- v2 在片尾前補一景課堂照（A07），讓「親自操作的體驗課」被看見，而不只被寫出來。字只寫「自己動手玩一次」，不寫人數、場地或要不要自備手機，因為這些還沒確認。照片是 AI 生成的示意畫面，不是真實課堂。
- A08（咖啡廳兩人看照片）和 A03 的作用重疊（都是給朋友看成果），A03 本身有「你也會用 AI 了？」這句，比較強，所以 A08 沒用。
- A03 的「你也會用 AI 了？」是朋友的反應，直接當成「分享」那一段的台詞，不另外加字蓋掉它。
- 字級最小 46px（約手機上 13–14pt），重點詞用黃色；字幕避開 IG/FB 底部約 300px 的按鈕區。
- **沒有旁白**：Reels／FB 多半靜音播放，所以字幕就是主角；配樂＋音效撐節奏。見下方「可加強」。

## 課程事實：用了什麼、沒寫什麼

- 片中唯一的課程事實：**費用 500 元**，以及「親手操作、第一次把 AI 用進生活、不是電腦課」（取自軍令第五節課程本質）。
- **日期、時間、地點、報名方式、名額、帶不帶手機、用哪個 AI App —— 都沒有寫進影片**，因為還沒拿到。片尾改成「請看貼文說明」。
- 對話畫面是**通用示意介面**，不指涉任何品牌 App；AI 的回覆文字是示意。
- 照片為 AI 生成：每張素材左上角原本的「AI生成」標示都保留，推鏡時以它為錨點，全片都不會被裁掉；片尾模糊背景另加「照片為 AI 生成示意」。

## 製作方式（全部在本機完成）

| 項目 | 做法 |
|---|---|
| 畫面 | Python＋Pillow 逐格繪製（推鏡、字卡彈入、示意對話畫面的聲波／打字動畫、快門閃光、閃光粒子），pipe 給 ffmpeg 輸出 900 格 |
| 3:4 照片（A01） | 寬度撐滿、上下用同一張照片的模糊版補滿，人物與「AI生成」標示都不裁 |
| 音樂 | 程式寫的 MIDI（100 BPM、F 大調，尼龍吉他＋鐘琴＋貝斯＋拍手，高潮加弦樂與旋律），FluidSynth＋FluidR3 GM 音色 |
| 剪輯 | 剪點全部對齊拍點：0／4.8／12.0／16.8／19.2／22.8／25.2；拍菜那一刀用快門閃光，其餘溶接或硬切 |
| 音效 | numpy 合成：快門、錄音開始／結束、打字、完成提示音、小卡彈出、訊息送出、高點閃光、whoosh |
| 混音 | 最後統一響度 -14 LUFS（Reels/FB 常用標準） |

原始碼在 [02-製作/source/](02-製作/source/)。

```bash
apt-get install -y ffmpeg fonts-noto-cjk fluidsynth fluid-soundfont-gm
pip install pillow numpy scipy mido
cd 02-製作/source
python3 music.py && fluidsynth -ni -g 0.7 -r 44100 -F music_raw.wav /usr/share/sounds/sf2/FluidR3_GM.sf2 music.mid
python3 mix.py music_raw.wav                       # → final_audio.wav
python3 render.py raw.mp4 final_audio.wav          # 約 3 分鐘
ffmpeg -i raw.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:a aac -b:a 192k -movflags +faststart ../60plus-AI生活體驗課-招生-30s-9x16.mp4
python3 cover.py                                   # → ../封面.jpg
python3 render.py --still 11.5 check.jpg           # 單格預覽
```

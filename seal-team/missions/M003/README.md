## 1. 原則：實拍負責「真」，即夢負責「動」

- **食物在鐵板上翻炒、上桌的畫面一律用實拍**（R1–R8）。即夢生成的食物可能長得跟實際出餐不一樣，放進廣告會有「圖文不符」風險。
- **即夢只用來把「靜態照片」變成有動態的鏡頭**：冒煙、熱氣、燈光閃、鏡頭推近。動作幅度要小，食物本身不能變形。
- 招牌、店名字樣（J07、J08、J09）在 AI 生成時容易字體變形，生成後**逐格檢查文字**；變形就改用照片本身＋剪映「縮放／推近」效果代替。

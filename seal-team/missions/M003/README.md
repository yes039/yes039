## 5. 第二輪才發現的缺陷

1. **`pick_take.py` 抓不到漏唱**：回報命中率 90.5%、無紅燈句子，但 take2 實際整句漏唱「下班之後 也能有進帳」。只能靠人耳發現。❌
2. **`align_subs.py` 對句錯行**：第二段主歌起，`_heard` 全部對到上一句；C 看出後改正，Whisper 的時間點本身可用。❌
3. **`build_mv.py` 用在照片會抖**：`render_fill()` 用 `int()` 截斷縮放尺寸與裁切位置，Ken Burns 每幀位移在 0–2 像素間跳動。v1 的扁平圖示看不出來，換成細節多的照片就很明顯。❌
4. 修正方式與優先順序見 [小曲缺陷與修正建議.md](小曲缺陷與修正建議.md)。

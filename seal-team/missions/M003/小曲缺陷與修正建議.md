## 1. `build_mv.py`：照片素材抖動 ✅ 已在副本驗證

**原因**：`render_fill()` 把縮放後尺寸與裁切位置用 `int()` 截斷。Ken Burns 每幀只移動不到 1 像素，截斷後實際位移在 0、1、2 像素之間跳動。扁平圖示看不出來，細節多的照片（臉、書架、便利貼）就會明顯抖動。

**修正**（M003 的 `build_mv_local.py` 已這樣改，店主驗收「不抖了」）：

```python
# 原本
nw, nh = max(W, int(sw * scale)), max(H, int(sh * scale))
x = max(0, min(nw - W, int((nw - W) * cx)))
y = max(0, min(nh - H, int((nh - H) * cy)))

# 改為（全程浮點，裁切 box 本來就接受浮點座標）
nw, nh = max(float(W), sw * scale), max(float(H), sh * scale)
x = max(0.0, min(nw - W, (nw - W) * cx))
y = max(0.0, min(nh - H, (nh - H) * cy))
```

`render_band()`、`render_fit()` 也有同樣的 `int()` 寫法，但這次沒用到，是否也會抖 🧪。

## 2. `pick_take.py`：抓不到漏唱 ✅ 已確認成因

**原因**：`hit()` 把 Whisper 聽到的**整首歌**變成一個字元集合，再算每句歌詞的字「有沒有出現在集合裡」。只要那句的字在歌曲**任何地方**出現過，就算命中。

M003 漏唱的「下班之後 也能有進帳」，「下班之後」出現在第一句、「也能」出現在「一個人也能」，所以照樣拿到高分，整首平均 90.5%、沒有任何 ❌。

**建議**（🧪）：

- 改成**按順序比對**：拿歌詞每一句，在 Whisper 逐段文字裡依序找最相似的片段（例如 `difflib.SequenceMatcher`），比對過的片段不能重複使用。
- 找不到對應片段的句子直接標 ❌「疑似漏唱」，並在最後總結列出。
- 挑 take 時，有漏唱的 take 直接降級，不只看平均分數。

## 3. `align_subs.py`：一句錯、後面全錯 ✅ 已確認成因

**原因**：字幕是用「第 i 段 Whisper 片段 ↔ 第 i 句歌詞」配對。Whisper 只要把兩句合成一段、把一句拆成兩段，或是歌手漏唱一句，後面每一句的時間都會錯開一行。M003 第二段主歌起整段錯位，就是這個原因。

腳本最後會印出「⚠️ 聽到的是：…」提醒，但不會自動修正。

**建議**（🧪）：

- 和第 2 點共用同一套「按順序比對」，用文字相似度決定每句歌詞對到哪一段，不要用 index 配對。
- 使用已經開啟的 `word_timestamps=True`，以字為單位取每句的開始與結束時間，處理一段含兩句的情況。
- 對不到片段的歌詞句不要寫進 `subs.json`（等於自動處理漏唱），並在輸出中列出。

## 4. 尾卡預設掛龍蝦學院 logo ✅

**原因**：`build_mv.py` 預設 `brand: true`，註解寫著「客戶自用商業片可在 mv.json 設 `"brand": false` 關掉」，但 SKILL.md 的流程沒有提醒要依尾卡品牌決定這個值。M003 的尾卡填了「AI 生意幫手」，小曲仍保留龍蝦 logo。

**建議**：在 SKILL.md 的收料問卷加一題「尾卡要不要掛龍蝦學院 logo？」，或規定只要尾卡品牌不是龍蝦學院，就寫入 `"brand": false`。

## 5. 缺工具時直接安裝 ✅

**原因**：`pick_take.py` 需要 Whisper，但 SKILL.md 沒有在開工前檢查。M003 缺 Whisper 時，Claude 直接執行 `pip3 install openai-whisper`（含 PyTorch，約 2GB），沒有先問；在 Homebrew Python 上這個指令本來就會被擋。

**建議**：

- SKILL.md 開工前的環境檢查加上 `python3 -c "import whisper"`，缺少時**停下來告訴使用者**，不要自行安裝。
- 寫明沒有 Whisper 時的降級方式：字幕依歌曲結構估算，並在 `subs.json` 註記「未經 Whisper 校對」。
- 安裝說明補上 Homebrew Python 要用 `python3 -m pip install --user --break-system-packages …`。

## 6. 小問題

| 問題 | 實測內容 | 建議 |
|---|---|---|
| 提示檔名不一致 | 原附 demo 出片後提示 `check_frames.py out/final.mp4`，實際檔名是 `demo_9x16.mp4` | 提示改為讀取 `mv.json` 的 `out` 欄位 |

| 素材來源標示 | v2 一開始把 Gemini 生成圖稱為「使用者提供的真實素材」，之後才更正 | 收料時要求標明素材來源（實拍／AI 生成／官網），合規檢查依來源套用不同規則，例如 AI 生成要提醒發布時勾選 AI 標示 |

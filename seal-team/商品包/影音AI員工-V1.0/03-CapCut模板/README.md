# 03｜CapCut 兩種可重複使用的模板

## 先說清楚：這兩個模板是怎麼「重複使用」的

C 沒有 CapCut，也不能直接產出 CapCut 專案檔。所以模板由三樣東西組成：

| 組成 | 內容 | 誰做 |
|---|---|---|
| ① 規格 | 每一格的秒數、用途、字卡位置與樣式（本文件） | 我方（已完成） |
| ② 素材包 | 佔位圖（每格一張，標好格號與秒數）＋原創配樂 2 首 | 我方（已完成，見 `素材/`） |
| ③ 母片 | 老闆在**自己的** CapCut 照規格建一次的專案，之後每支片都從母片複製、逐格「取代」成新素材、改字 | 老闆（第一次上課時，教練陪同，約 20～30 分鐘【推估】） |

**跨店重複使用**：規格與素材包每家店都一樣；每家店只是在自己手機上建一次母片。

**每支新片**：複製母片 → 逐格取代 → 改字 → 匯出。不需要重新排秒數、不需要重新找音樂。

> ⚠️ CapCut 的按鈕名稱會因版本、語言設定而不同。下文的按鈕名稱是依一般操作整理，**要在 Shen 演練時逐一確認**，並把實際畫面補進教材。

## 共同規格（兩個模板都一樣）

| 項目 | 規格 |
|---|---|
| 畫面比例 | 9:16 |
| 匯出 | 1080p、30 fps |
| 片長 | 30 秒（允許 29～31 秒） |
| 字卡位置 | 畫面中間偏下的框內（佔位圖上的白框）；上面 10%、下面 20% 不放字（會被平台按鈕蓋住） |
| 字卡樣式 | 白字＋黑色外框（或半透明黑底），字級大到手機一眼看得清；全片同一種字型 |
| 字型 | 用 CapCut 預設字型。**不要選標示 Pro 的字型**（匯出會有浮水印或要付費）。CapCut 字型的商用條款見 [06 查證](../06-CapCut免費版與音樂授權查證.md) |
| 特效、貼圖、濾鏡 | V1.0 不用。越少越不容易出錯，也避開 Pro 素材 |
| 轉場 | V1.0 不用（直接切）。轉場是否影響總秒數，演練後再決定要不要加 |
| 音樂 | **只用素材包的原創配樂**。不用 CapCut 內建音樂與音效（理由見 06 查證） |
| CapCut 自動片尾 | 一定要刪掉（或在設定裡關掉「自動新增片尾」） |

## 建立母片（每家店做一次）

1. 把 `素材/佔位圖-模板A/`（或 B）的圖片和兩首配樂存到老闆手機相簿或檔案。
2. CapCut →「新專案」→ **依檔名順序**選佔位圖 A01～A08 →「新增」。
3. 「比例」設 9:16。
4. 逐格調整長度，讓每格符合上表（點選片段，拖曳邊緣，畫面會顯示秒數）。完成後總長應為 30.0 秒。
5. 「音訊」→ 從裝置匯入音樂 → 選 A-溫暖-30s.m4a，對齊 0 秒。
6. 「文字」→ 逐格新增字卡：放在佔位圖白框內，長度對齊該格；內容先打「格1字卡」「格2字卡」…。設定好第一個字卡的樣式後，其他字卡用「複製」保持一致。
7. 刪掉 CapCut 自動加的片尾。
8. 專案改名「母片A（勿改）」。
9. 模板 B 照同樣步驟再做一次，名稱「母片B（勿改）」。
10. 匯出一次測試（1080p），確認 30 秒、字在框內、沒有浮水印。

## 每支新片（老闆日常操作）

1. 在 CapCut 專案列表，把「母片A」或「母片B」**複製一份**，改名成這支片的名稱。
2. 打開複製出來的專案，依影音小幫手的《剪輯卡》，**一格一格「取代」**：點該格 →「取代」→ 從相簿選素材 → 影片可以拖動選要用哪一段。
3. 一格一格改字：點字卡 → 編輯 → 貼上剪輯卡的字。
4. 模板 B：檢查每格影片的原音有沒有開著。
5. 刪掉 CapCut 自動片尾（如果又出現）。
6. 匯出 1080p。
7. 截 3 張圖（開場、中間、片尾）傳給影音小幫手檢查。

**備案**：如果「複製專案」在老闆的 CapCut 版本找不到，改成每次重新照「建立母片」第 2～7 步做一次，用剪輯卡的素材直接代替佔位圖（約多 10～15 分鐘【推估】）。

## 素材包內容（`素材/`）

| 檔案 | 說明 |
|---|---|
| `佔位圖-模板A/A01～A08.jpg` | 1080×1920，標格號、秒數、用途、字卡框、平台遮擋區 |
| `佔位圖-模板B/B01～B10.jpg` | 同上 |
| `A-溫暖-30s.m4a` | 原創配樂：90 BPM，C 大調鋼琴分解和弦＋暖墊＋沙鈴；30.0 秒、整合響度 -16.3 LUFS、最後 2 秒淡出 |
| `B-輕快-30s.m4a` | 原創配樂：120 BPM，G 大調撥弦＋貝斯＋大鼓拍手；30.0 秒、-16.3 LUFS、最後 2 秒淡出 |
| `source/make_music.py`、`source/make_placeholders.py` | 重新產生用的腳本（numpy 合成、Pillow 繪圖） |

**配樂授權**：純程式合成，沒有取樣、沒有外部音色庫，我方自有，可以給客戶用在商業影片、任何平台。
**C 聽不到聲音**：兩首配樂只量過響度與連續性（每 3 秒一段的平均音量穩定，結尾淡出）。**好不好聽、適不適合店家，要 Shen 驗收時親耳聽**；不合適就退回重做。

重新產生：

```bash
python3 source/make_music.py <暫存資料夾>
ffmpeg -i <暫存資料夾>/A-溫暖-30s.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 -c:a aac -b:a 192k A-溫暖-30s.m4a
ffmpeg -i <暫存資料夾>/B-輕快-30s.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 -c:a aac -b:a 192k B-輕快-30s.m4a
python3 source/make_placeholders.py . <中文字型檔>
```

佔位圖用文泉驛正黑繪製，只在建母片時出現、成片裡不會留下。

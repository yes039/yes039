# 交付五｜G1 第一輪實測操作清單（給 POS 操作人員）

> **這份清單需在總指揮核准 G1 後才可執行。**
> 測試期間：**2026-10-26（一）至 2026-11-01（日）**，共一週。
> 預計時間：60–90 分鐘。需要：**總部後台帳號**（能看所有報表即可，不需要管理員權限）、一個隨身碟或雲端資料夾 `G1_原始檔/`。

## ⛔ 安全守則（開始前請先讀完）

1. **只做「查詢、預覽、列印、匯出」**。看到「新增、刪除、存檔、作廢、結案、更新」按鈕一律**不要按**。
2. **絕對不要進入**「系統相關 → 資料傳輸」裡的 **「手動傳輸」「總部全面下傳」**。全面下傳會刪除分店資料（手冊 p140）。這兩個畫面**只截圖，不點任何按鈕**。
3. 不要修改任何參數設定。如果不小心改到，請按「取消」或「結束」，**不要按「存檔」**。
4. 匯出的檔案**先不要傳給任何人或上傳到 AI**，先交給 C-001 做去識別處理。
5. 截圖時，如果畫面出現顧客電話、姓名、地址，請用馬賽克遮住，或略過該畫面。

## 步驟 2｜報表匯出能力測試（最關鍵）

**每一張報表都照這個流程做：**
① 開啟報表 → ② 截圖**查詢條件畫面** → ③ 日期填 2026-10-26～2026-11-01 → ④ 按預覽或列印 → ⑤ 截圖**結果畫面**（要能看到欄位標題）→ ⑥ 在預覽畫面找找看有沒有 **匯出、存檔、Excel、磁碟片圖示、另存新檔** → ⑦ 有的話，**每一種格式都試一次**（Excel、CSV、PDF、TXT）→ ⑧ 都沒有的話，在列印時選印表機「**Microsoft Print to PDF**」另存成 PDF。

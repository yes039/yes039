## 五個問題，一句話回答

1. **能否輸出 Excel、CSV？** 手冊只證明「可以列印」。Excel、CSV **無證據（D）**，必須在 G1 實機確認。
2. **可以取得哪些資料？** 營業、商品、付款、會員資料豐富（A）；採購、庫存、成本、薪資有缺口（D）。
3. **能否取得逐筆、每日、每小時、班別明細？** 每日、班別有報表（A）；每小時的切分粒度待確認（C）；逐筆資料存在，但無法批次取出（D）。
4. **如何交給 Claude？** 依序為：匯出、去除個資、依資料字典標準化、通過 10 條驗證規則，再上傳到 Claude Project 進行分析。
5. **能否自動化？** 短期可做到半自動（L0、L1）。全自動需要廠商提供排程匯出或唯讀介接（D，待廠商書面回覆）。

## KPI 重大提醒

三項目標合計 40 萬，與「淨效益 ≥ 30 萬」之間的 **10 萬差額**，應正式定義為扣除上限，涵蓋四項：重疊、增額人力、自我侵蝕、執行成本。**新增營收一律不得直接當成毛利計算。** 詳見交付三 E 節。

## 建議：**Conditional Go**（有條件進入 G1）

**理由**：銷售面的資料確實存在且相當豐富，足以支撐 A 整體經營分析與 C 三增方案的時段分析。但目前「能否取出成檔案」與「採購、成本、工時資料是否存在」都還沒有證據，不能直接進入開發。

**進入 G1 的條件**：

1. 總部提供**報表查詢權限**的帳號（不需要管理員權限），由店內人員依交付五操作。C-001 不直接登入 POS。
2. 同步以書面向廠商送出 11 個問題（交付一第 4 節）。
3. 所有匯出檔都要先完成去識別處理，才能交給 AI。

**G1 結束後的判定門檻**：

| 結果 | 判定 |
|---|---|
| 主要報表可匯出 Excel 或 CSV，或可穩定列印成 PDF 並轉換，且通過 V1、V2 對帳 | **Go**：進入 L0 每週分析 |
| 只能看畫面、無法列印成 PDF，廠商也不提供匯出 | **No-Go（POS 路線）**：改以手抄日報與外部 Excel 為主 |
| 銷售資料可取得，但採購、成本模組不存在 | **Go（A、C、D 三項）**；B 採購成本分析改用外部 X1–X3 |

等待總指揮核准。

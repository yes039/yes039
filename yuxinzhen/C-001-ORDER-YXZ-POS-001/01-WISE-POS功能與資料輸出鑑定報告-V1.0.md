## 3. 對五個問題的鑑定結論

| 問題 | 結論 | 等級 |
|---|---|---|
| **Q1 能否輸出 Excel、CSV？** | 手冊**只證明能列印**。無論哪個畫面，都**沒有證據**顯示能匯出 Excel 或 CSV。這類 Windows 版後台的報表預覽，常附有「存成 Excel／PDF」功能，但這只是推論，等級 C，**必須在 G1 實機確認**。保底做法是把報表「列印」到 PDF 印表機，再轉成結構化資料（路線 D），等級 C | Excel D／PDF 保底 C |
| **Q2 有哪些資料可以取得？** | **營業與商品**：豐富，34 張報表 A。**會員**：有，但屬個資。**採購、進貨、庫存、盤點**：手冊沒有任何畫面或報表，玉欣珍可能沒有開通，D。**成本**：手冊所列商品欄位中沒有成本，D | 見交付二 |
| **Q3 逐筆、每日、每小時、班別？** | **逐筆**：資料存在（O01 單頭與單身欄位齊全，含時間）A，但**批次取出的方式 D**。**每日**：日銷售統計表 A。**每小時**：收銀時段分析表存在 A，切分粒度 C。**班別**：班別銷售統計表 A，搭配 POS 交班檔 B | — |
| **Q4 如何交給 Claude？** | 先走路線 A：手動匯出 Excel。若做不到，退回路線 D：列印成 PDF 再轉換。檔案先去除個資，再依資料字典標準化，最後交給 Claude 分析 | 規劃 |

## 4. 需補拍畫面與向廠商詢問的問題（摘要）

1. 報表預覽或列印畫面是否有「匯出 Excel、CSV、PDF」功能？是否需要權限或另外授權？

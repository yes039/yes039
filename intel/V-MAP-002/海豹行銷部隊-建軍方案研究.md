### 0.2 研究重心改變

V-MAP 001 問的是「我們做一支片要花多少錢」。V-MAP 002 改問「**老闆學不學得會，離開我們之後還會不會繼續做**」。

這兩個問題的選器結果不一樣。最好的生成模型（Veo、Runway）幾乎都不適合交給老闆自己用。

### 0.3 六個研究問題，一句話回答

| 問題 | 答案 |
|---|---|
| 哪些工具最容易讓老闆學會？ | **Claude（對話）、Meta Business Suite、CapCut 模板、Canva 模板**。共同點：都是手機或網頁介面、不需要寫提示詞技巧、做錯可以馬上重來 |

### 2.4 刻意不做的事

- **不串 FB API 自動發文**：Meta 的貼文與 Reels API 需要 `pages_manage_posts` 等權限，要通過應用程式審查與商家驗證，權杖約 60 天會過期（✅ Meta 官方文件＋第三方指南）。交給每位老闆自己維護等於部署 N 套會壞的系統。**發布一律由老闆在 Business Suite 手動排程**，沿用既有人工節點 H5。
- **不讓 AI 直接回覆留言**：Claude 只提供回覆建議。Business Suite 的原生自動回覆只用在營業時間、地址、價格這類常見問題。
- **不用 Gemini 或 ChatGPT 當第二窗口**：遵守「維持 Claude 為唯一大腦」的原則。

## 3. 海豹三兵任務分工及交接流程

### 3.1 設計前提（來自既有診斷）

`架構診斷-裸Claude-vs-多兵.md` 的結論是：**錯的不是多兵，是切口切在創作迴路中間**（企劃與製作被拆開，交接時視覺判斷被壓成文字）。所以新三兵**依作品切分，不依工序切分**：

- 每個兵從頭到尾負責一種作品：貼文、影片、戰果。
- 戰果兵保持獨立，因為「自己評自己的作品」不可信。
- 三兵放在**同一個 Claude Project**，用指令叫出（「文宣兵出列」），老闆只需要管一個窗口。是否改成三個 Project，見決策 E1。

### 3.2 三兵職責

| 兵 | 負責到底的作品 | 輸入 | 輸出 | 不做 |
|---|---|---|---|---|
| **① 文宣兵** | FB 貼文（文字＋圖卡）、每月內容月曆 | 店家資料卡、本週主題、戰果庫 | 貼文稿 2 版（長、短）、圖卡（Canva）、主題標籤、發布時段建議 | 不寫未確認的事實、價格或優惠；不用 AI 生成菜色圖 |
| **② 影音兵** | 每週短影音（照片成片或混剪） | 拍攝指令單、老闆上傳的素材、固定格式模板 | 拍攝指令單 → 素材判讀（哪幾段可用）→ 剪輯單（逐鏡秒數）＋字幕 .srt＋封面字＋發文文案 | 不幫老闆剪；不推薦格式以外的花樣（固定格式是穩定的來源） |
| **③ 戰果兵** | 經營管理與判讀：留言回覆建議、週報、月復盤 | 洞察截圖、留言截圖、作品紀錄 | 回覆建議 2～3 版、週報、追加戰果庫、下週一個調整建議 | 不判斷自己沒看到的數據；觀看數低於門檻時寫「無法判定」 |

### 3.3 交接流程

```
月初  老闆＋文宣兵 ──→《月作戰令》（本月 3 個主題、要推的品項、禁區）── 老闆核可 H1
        │
每週    ├─ 文宣兵 ──→《貼文稿》──→ 老闆核可 H2 ──→ Business Suite 排程 H3
        │
        ├─ 影音兵 ──→《拍攝指令單》──→ 老闆拍 H4 ──→ 素材 ──→ 影音兵《剪輯單＋字幕＋文案》
        │                                                    ──→ 老闆組片（CapCut）H5 ──→ 核可、排程 H3
        │
        └─ 每天：留言截圖 ──→ 戰果兵《回覆建議》──→ 老闆選一個、回覆 H6
週日  洞察截圖 H7 ──→ 戰果兵《週報》──→ 戰果庫 ──→ 下週文宣兵、影音兵開場必讀
月底  戰果兵《月復盤》──→ 下個月《月作戰令》
```

**交接規則（沿用既有規則並簡化）**

1. **共用編號**：`2026-11-W1-P1`（第 1 週第 1 篇貼文）、`2026-11-W1-V1`（第 1 週第 1 支影片）。戰果兵只用這組編號判讀。
2. **交接時傳原始素材，不只傳描述**：影音兵直接看照片（Claude 可以看圖）。影片則請老闆截 1～3 張畫面＋一句描述，因為 Claude 無法直接看影片檔（沿用 README 第 7 節的限制）。
3. **退回要寫原因**：老闆退稿時要說一句原因，兵把它寫進戰果庫「店家口味」欄，下次就不會再犯（來自 B001 的退回紀錄做法）。
4. **換器前先換提示詞**（沿用武器配置表的共通規則）。

壓力測試指出，老闆腦中**沒有「能力費」這個帳戶**，會自動拿最便宜的東西來比。所以報價單上要主動列出比較基準：

## 一頁結論

1. **兩個市場買的東西不一樣**：店家買的是「我的粉專自己動起來」，學員買的是「我能接案的一套本事」。核心技術可以共用，**驗收對象不同**。A 驗的是老闆自己的粉專，B 驗的是學員交給「別人」的作品，以及背後的責任。
2. **共用核心＝三堂課＋同一套部隊模板**。A 與 B 的學員**混班**上同一個核心梯次，B 再加三堂分流課。這是第二市場不會讓成本失控的關鍵。
3. **V-MAP 002 的工時問題已經修正，前提是遵守開班門檻**：
   - 在開班門檻下限（核心梯次 4 人、B 分流 3 人）：A 每客約 **5.0 小時**（毛利約 54%）、B 每客約 **8.0 小時**（毛利約 45%）。
   - 建議的試點梯次（3 位店家＋3 位學員）：A 約 4.5 小時（58%）、B 約 7.5 小時（48%）。
   - 前提是遵守開班門檻，並且由 C 先審作品、扮演模擬客戶。
   - 如果退回到全 1 對 1，A 約 9.5 小時、B 約 16.5 小時，**兩案都會虧損**（扣除獲客成本後）。
   - 另外更正 V-MAP 002 的一處引用：「12,800 在 6～8 小時可守住 55～65% 毛利」**過於樂觀**。依同一份壓力測試的假設重算，6 小時毛利只有約 46%。
4. **B 的最大風險不是技術，是責任與承諾**：
   - 學員一收錢，就要對客戶負責，包括授權、個資、帳號權限、修改範圍。
   - 招生文案只要碰到「接案收入」，就有不實廣告的風險。
   - 所以 B 的結業驗收包含一套**交付責任包**（合約要點、授權清單、權限交接、個資處理），而且全產品線不承諾收入。
5. **建議的最小試點**：一個混合梯次（3 位店家＋3 位學員），用試點價加可退押金，驗證三件事：
   - 店家交付後是否持續自己做。
   - 學員能否交出 L2 等級的模擬案。
   - 我方實際工時是否守住預算。

> 本文的每一個階段**都需要 Shen 另行核准**才能開始。本次只提出設計。

|---|---|---|---|

| **H0-B** | 學員在 6 週內能交出 L2 等級、責任交代清楚的交付包 | 不成立，B 等於賣「學不會的接案課」，客訴與退款風險最高 | 本次新增 |

## 2. 分階段驗證

### 第 0 階段｜內部演練（約 2 週，不花錢、不招人）

**前提**：Shen 核准進入建置，才能做以下準備。

| 準備項目 | 用什麼做 | 完成標準 |
|---|---|---|
| C0 部隊模板（客戶版、學員版） | 改寫自 `seal-team/roles` 與 B001，**另存新檔，不改原檔** | Shen 核可 |
| 兩種 CapCut 固定格式＋示範片 | 宜大鐵板燒素材（M003） | 用模板做出 ≥ 4 支，C 自評 ≥ 3 支達 L1 |
| C 先審提示詞、模擬客戶劇本 2 份 | 由 C 撰寫 | Shen 核可劇本 |
| 報價單、需求單、合約要點、授權清單 | 由 C 撰寫 | **律師審閱合約要點**（唯一可能的外部費用，需另行核准） |
| 內部演練 | C 用宜大素材跑完整的 A 流程；再用模擬客戶跑一次 B 流程 | 產出 ≥ 10 件作品，≥ 7 件通過 F／L 檢核（沿用壓力測試的前置條件） |

### 第 1 階段｜B 市場需求測水溫（與第 0 階段同時進行，不花錢）

- 用 FB 十問的「觀點＋案例＋問題」格式，在 Shen 的帳號發 2～3 題給 B 族群（例：「如果你會用 AI 替小店做 FB 和短影音，你最擔心的是什麼？」）。
- **只採計中級以上的訊號**：私訊、索取資料、加 LINE、願意約通話（沿用 FB 十問的訊號分級）。
- 判讀門檻：3 篇合計 ≥ 5 個中級以上訊號，才招募 B 試點學員；否則先只做 A。
- 文案遵守 01 文件的招生用語清單，**不提收入**。

### 第 2 階段｜混合試點梯次（6 週＋結業後 8 週追蹤）

| 項目 | 設計 |
|---|---|
| 人數 | 3 位店家（A）＋3 位學員（B），核心課混班 |
| 店家招募條件 | 單店、老闆在現場、有粉專、過去 3 個月內試過發短影音後停了；排除「全部幫我做」型（沿用壓力測試） |
| 學員招募條件 | 會用手機和電腦、每週能投入 4 小時、簽署「不保證收入、不提供客源」確認書 |
| 試點價（建議） | 候選價的 50%（A NT$6,400、B NT$8,400），其中 NT$1,000 是押金：A 達成合約驗收、B 通過結業驗收就退還。試點價**不對外公開**，參與者需同意試點價不延續到正式方案 |
| 我方要記錄的 | 每人實際工時（教練打卡）、C 先審與教練判定的一致率、每一則支援訊息與分鐘數、卡關點、退回原因 |
| 不做的 | 不保證試點參與者任何成效；不轉介真實客戶給學員 |

### 試點判讀門檻

| 結果 | 判定 | 下一步 |
|---|---|---|
| A：≥ 2／3 位通過合約驗收，且結業後第 3～8 週 ≥ 2／3 位達 H1 | A 成立 | 以 12,800 開第一個正式梯次 |
| A：H1 達標 < 1／2 | **A 不成立** | 重新思考 A 的形式（例如改成「建置＋付費續航」），不開正式梯次 |
| B：≥ 2／3 位結業驗收通過（OB5 達 L2、OB6 合格） | B 成立 | 以 16,800 開第一個正式梯次 |
| B：OB5 不通過超過一半 | **B 教學不足以支撐收費交付** | 延長 B 分流或降低定位，不開正式梯次 |
| 任一案實際工時超出預算 20% 以上 | **成本不成立** | 先修正工時（05 文件第 6 節），再決定是否開班 |
| C 先審一致率 < 80% | 先修提示詞 | 修正後才能開正式梯次 |

### 第 3 階段｜正式梯次（試點結果決定）

- 只有在第 2 階段判定「成立」的路線才開正式梯次。
- 正式梯次遵守開班門檻與成本控制規則（05 文件第 6 節）。
- 每個梯次結束後，更新 FAQ、驗收數據與實際工時，作為下一個梯次的定價與設計依據。

## 3. 時程（建議）

| 週 | 內容 |
|---|---|
| 第 1～2 週 | 第 0 階段內部演練＋第 1 階段 FB 測水溫 |
| 第 3 週 | 招募試點（店家從人脈外一層、在地老闆社團；學員從測水溫的回應者） |
| 第 4～9 週 | 試點梯次（A 第 4～7 週結束；B 第 4～9 週結束） |
| 第 10～17 週 | 結業後追蹤（A 的 H1 在結業後第 3～8 週量測） |
| 第 17 週 | 試點總結，送 Shen 決定是否開正式梯次 |

## 4. 試點不會回答的問題（避免過度解讀）

- 6 人的樣本無法證明市場規模，只能證明「流程與成本」是否成立。
- 試點價下的付費意願，不等於候選價下的付費意願。
- B 學員結業後能不能接到真實案件，**不是本試點的判讀項目**（也不會對外宣稱）。

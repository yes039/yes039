# 01｜雙市場產品定位與客群分析

> 標記：✅ 已核實　🟡 待查證　【推論】依資料推得，未驗證
> 原則：不承諾流量、營收或接案收入。

## 1. 一句話定位

| | A｜店家自用版 | B｜接案變現版 |
|---|---|---|
| 一句話 | **幫你的店建一支 AI 行銷部隊，教到你自己帶得動** | **學會用一支 AI 行銷部隊，替小店交付 FB 貼文與短影音** |
| 買的是 | 自己粉專的持續運作 | 一套能交付給別人的工作方法 |
| 成果歸屬 | 店家自己的粉專、自己的帳號 | 學員的作品集與交付能力（**不含客戶來源**） |
| 不是 | 代工、代操 | 保證接案、包客源、創業加盟 |

## 2. 客群輪廓

### A｜店家自用

| 項目 | 內容 | 依據 |
|---|---|---|
| 對象 | 單店、老闆或店長在現場的餐飲、美甲、寵物、民宿、補習與課程業 | V-MAP 001／002 |
| 年齡 | 28～55 歲，晚上 21:00～24:00 滑 FB | FB 三部曲 0-2 |
| 現況 | 有粉專，但更新斷斷續續；試過自己拍短影音後停了 | 壓力測試的招募條件 |
| 真正的痛 | 時間與精力，不是能力。「不知道要拍什麼、拍了也不知道怎麼剪」 | 壓力測試 ①② |
| 會拿來比的 | 外包剪輯每支 NT$1,000～3,000、代操每月 NT$1～2 萬（實際發案預算）、免費的政府課 | V-MAP 001 ✅、PRO360 🟡 |
| 排除 | 「全部幫我做」型（這是代工客戶）、連鎖總部、已有小編的店 | V-MAP 002 4.2 |

### B｜接案變現

| 項目 | 內容 | 依據 |
|---|---|---|
| 對象（推估四群） | ① 想要彈性收入的二度就業者 ② 想開發副業的上班族 ③ 已在接設計或小編案、想加 AI 提高效率的人 ④ 熟悉在地店家人脈的退休族或熟齡者（與 Shen 既有的「60+ 學 AI」受眾重疊） | 【推論】；④ 參考 M002 招生片受眾 |
| 真正的動機 | 「能不能賺到錢」優先於「學會技能」 | 【推論】 |
| 會拿來比的 | 線上小編、Canva 課（數百到數千元）、政府或大學免費課、加盟或創業課 | 🟡 |
| 接案市場行情 | 單則圖文 NT$500～2,000；小店 IG 代操發案預算 NT$3,000～8,000／月；社群代操 NT$5,000～50,000／月 | PRO360 價格頁與發案紀錄 🟡 |
| 排除 | 期待「上完課就有客戶」的人；不能接受「我們不提供客源」的人 | 為了降低退款與客訴風險 |

## 3. 購買動機與風險比較

| 面向 | A 店家 | B 學員 |
|---|---|---|
| 心理帳戶（依心理帳戶分析） | 「系統導入」或「學費」，要看交付形式 | 「學費／投資自己」，但期待「回本」 |
| 付款前最在意 | 我每週要花多少時間？做出來的東西能不能發？ | 學完能不能接案？要多久回本？ |
| 付款後期待我們負責 | 系統能用、教到會 | 教到會、作品能拿去提案，**常會期待「幫我介紹客戶」** |
| 最容易客訴 | 「我以為你們會幫我做」 | 「上完課接不到案」 |
| 成功的證據 | 交付後第 3～8 週還在自己發文（H1） | 能交出合格的模擬案與真實案作品（B 驗收） |
| 最大的合規風險 | 不實廣告：AI 修飾菜色（D3） | 招生文案暗示收入（公平法第 21 條的一般規範 🟡）；學員交付時的授權與個資責任 |
| 轉介潛力 | 老闆圈口碑 | 學員本身就是 A 的潛在推廣者【推論】 |

## 4. 兩個市場的關係（要小心的地方）

1. **會互相導流，但不能互相承諾**：A 會婉拒「全部幫我做」型的店家，B 結業學員正好能服務這類店家。但如果由我方把店家轉給學員，我方就要為學員的交付品質背書。**建議第一階段不做轉介**（決策 F4）。
2. **同一套核心，兩種驗收**：A 驗的是「老闆自己的粉專有沒有動起來」；B 驗的是「學員交給別人的作品合不合格、責任有沒有交代清楚」。教學內容 70% 相同，驗收標準完全不同（見 04 文件）。
3. **B 的招生用語清單**（建議寫進招生守則）

| 可以說 | 不可以說 |
|---|---|
| 你會學到替小店交付 FB 貼文與短影音的完整流程 | 保證接案、月入〇萬、學完就能回本 |
| 結業時你會有 2 個完整的交付案例作品 | 我們提供客源、包接案 |
| 這是市場上公開的接案行情（附來源）：〇〇～〇〇 | 學員平均收入〇〇（沒有真實統計前一律不寫） |
| 交付流程包含合約、授權、個資的基本守則 | 有了 AI 就不需要專業 |

> 依據：公平交易法第 21 條禁止對影響交易決定的事項做虛偽或引人錯誤的表示。這次沒有找到針對「接案或斜槓課程保證收入」的處分案例 🟡，但同一條款對廣告主的責任適用於所有產業。

- B 市場的需求規模、願付價格**沒有任何直接資料**；以上客群是推論。試點前應先用 FB 十問的方法，針對 B 族群發 2～3 題測水溫（不花錢，屬於既有方法）。
- 接案行情來自接案平台自己整理的資料，未標明年份 🟡。

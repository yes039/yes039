| 測試 | 狀態 | 原因 |
|---|---|---|
| T1 | ⏳ 未執行 | 本雲端環境沒有 Claude 或 Gemini API 金鑰；V4.2 的 system prompt 也還沒取得 |

| T3 | ⏳ 未執行 | 要用店主自己的 Google 帳號操作 Gemini Notebook |

**下面沒有任何實測數字。** 表格留空，跑完由 `harness/run_test.py` 產生的 CSV 回填。

## 怎麼跑

```bash
cd opc/P001/harness
pip install anthropic google-genai
export ANTHROPIC_API_KEY=...   # 或已執行 ant auth login
export GEMINI_API_KEY=...
python3 run_test.py cases/T1_豆花_粉專_曝光.json      # 跑全部模型各 2 次
python3 run_test.py cases/T2_M002_素材描述.json
```

輸出：`results/<case>_<時間>.csv`（tokens、延遲、NT$）與 `results/<case>_<時間>/<模型>_<次>.md`（原文，用來盲評）。

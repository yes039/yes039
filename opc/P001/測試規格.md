# 三項實際工作測試規格

共通規則
- **同題同料**：同一測試裡，各模型拿到一字不差的 system prompt 和輸入。
- **一次一變數**：只換模型，不順手改 Prompt（武器配置表共通規則 3）。
- **盲評**：評分者看到的輸出標成 A／B／C，評完才揭曉是哪個模型。
- **資料授權**：只用虛構店家、自製 M002 素材、本 repo 自有文件。客戶實拍素材要先取得書面同意。
- **每案跑 2 次**，取平均，看穩定度。
- 紀錄一律寫進 `results/`（腳本自動產生 CSV）＋〈測試紀錄.md〉。

## T1｜FB 貼文產生（對應 V4.2）

**目的**：V4.2 的核心工作換成 Gemini 做，品質、改稿時間、成本會不會比較好。

**輸入**：`harness/cases/T1_*.json`（虛構店家「巷口豆花」＋我們自己的「60+ 學 AI」）
- 發文主體：V4.2 的 4 個主體（目前 case 檔放了「FB 個人帳號」「粉絲專頁」兩個，**另外兩個請照 V4.2 的選項名稱補上**）
- 貼文目標 × 2：曝光互動、到店／報名轉換
- System prompt：**從 V4.2 原始碼複製**（不修改 V4.2，只是讀出來）。複製之前 case 檔先放一份占位 Prompt

**受測模型**：Claude Opus 5.5（現行）、Gemini 3.8 Flash、Gemini 4 Argon。可選：Claude Sonnet 5.5（成本對照）

**評分表**（每篇 1–5 分，隊長＋1 位非技術者各評一次）

| 指標 | 定義 |
|---|---|
| 口吻符合主體 | 個人帳號像本人說話；粉專像店家 |
| CTA 清楚且可兌現 | 有、唯一、讀者知道下一步 |
| 事實不捏造 | 沒有 brief 外的價格、優惠、療效、保證 |
| 可直接發布 | 不改字就敢發 = 5 |
| 改稿時間 | 實際計時（秒），改到願意發為止 |

另外由腳本記錄：輸入／輸出／思考 tokens、延遲、單篇 NT$。

**判定門檻**
- Gemini 某模型「品質平均 ≥ Opus 5.5」**且**「改稿時間少 ≥ 30%」→ 寫進復盤，作為 V5 的換器候選（**不改 V4.2**）
- 只有成本較低、品質較差 → 維持現狀
- 任何一篇捏造事實 → 該模型這項測試直接判不通過

## T2｜影片素材 → 素材清單＋剪輯單（對應製片兵）

**目的**：驗證武器配置表的換器條件：「素材以影片為主時，素材描述是否改由 Gemini 做」。

**輸入**：`seal-team/missions/M002/02-製作/60plus學AI-招生-30s-9x16.mp4`（自製、無客戶資料）
- Claude：每 5 秒抽一張畫面（共 6 張）＋同一段文字指令（Claude 不能直接讀影片）
- Gemini：直接上傳 mp4＋同一段文字指令
- 標準答案：`M002/README.md` 的分鏡表（時間碼、畫面、字幕）

**指標**

| 指標 | 算法 |
|---|---|
| 鏡頭描述正確率 | 9 個鏡頭中描述正確的數量 ÷ 9 |
| 時間碼可用率 | 起訖時間誤差 ≤ 1 秒的鏡頭 ÷ 9 |
| 字幕／旁白辨識 | 與 `字幕.srt` 比對，逐句正確數 |
| 幻覺 | 描述出影片裡沒有的東西，次數 |
| 成本與延遲 | 腳本記錄 |

**判定門檻**：Gemini 鏡頭正確率與時間碼可用率都比 Claude 高 ≥ 20 個百分點、且幻覺不比 Claude 多 → 製片兵的「素材描述」子任務換成 Gemini 主器（記錄在復盤）。

## T3｜Gemini Notebook 共創 vs 我們的流程（對應 M002／課程教材）

**目的**：這次新功能（先審大綱再產出）能不能取代我們做「教材簡報」與「說明短片」。

**前置**：用**我們自己的** Google 帳號確認 Notebook 有 Review 開關（如果只限 Ultra，記下方案與月費，**不另外升級付費**，先回報）。

**Notebook 來源**（只放自有文件）：`seal-team/README.md`、`seal-team/missions/M002/README.md`、自寫的「60+ 學 AI 第 1 課：按住說話、拍照問、請它寫字」講義（一頁）

**產出**
1. 10 頁以內簡報（匯出 PPTX）
2. 約 60 秒直式影片總覽

**流程紀錄**：大綱審查時改了幾處、要求了什麼、改幾輪才滿意、總工時（分鐘）。

**對照組**：M002 現行流程（或 Claude 產出簡報大綱＋人工排版）同題的工時與結果。

**評分表（1–5 分）**

| 指標 | 說明 |
|---|---|
| 內容正確 | 不偏離來源 |
| 長輩友善 | 字大、步驟少、用語白話 |
| 品牌／口吻可控 | 能不能指定色系、字型、旁白語氣、結尾 CTA |
| 可當招生廣告用 | 9:16、前 3 秒鉤子、報名卡 |
| 可再編輯 | PPTX 能不能直接改 |

**判定門檻**
- 教材類：內容正確 ≥ 4 且長輩友善 ≥ 4，工時 ≤ 現行的 50% → 教材改用 Notebook
- 廣告類：「品牌可控」與「可當招生廣告用」都 ≥ 4，才考慮取代 M002 流程；否則 M002 繼續自建

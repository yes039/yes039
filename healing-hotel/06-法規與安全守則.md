# ⑥ 法規與安全守則（以台灣為主，開業前務必請律師與主管機關確認）

> 療癒酒店最大的風險不是生意不好，而是**誇大宣稱**與**熱療意外**。以下是必須寫進 SOP 的紅線。

## 1. 宣稱用語紅線

食品、化粧品、按摩服務都**不得宣稱醫療效能**（參考《食品安全衛生管理法》第 28 條、《化粧品衛生安全管理法》第 10 條、《醫療法》第 84、86 條）。

| ❌ 不能說 | ✅ 可以說 |
|---|---|
| 治療失眠、根治失眠 | 營造好眠環境、睡前放鬆、幫助調整作息 |
| 排毒、清除體內毒素（食品/化粧品標示） | 促進代謝、輕盈感、溫熱舒緩 |
| 降血壓、改善糖尿病 | （避免任何疾病名稱） |
| 精油治療焦慮 | 香氣帶來平靜感、舒緩情緒 |
| 藥浴治病 | 草本泡浴、溫熱放鬆 |
| 中醫治療 | 體質諮詢、養生調理 |

> 本方案內部用語「排毒・排濕・排熱」屬傳統養生概念，**對外文宣**建議改寫為「輕盈疏通」「祛濕溫養」「清爽調理」等說法。

## 2. 人員資格

| 項目 | 要求 |
|---|---|
| 中醫診斷、開方、針灸 | 必須由**中醫師**執行，且在合法醫療機構內（可與合作中醫診所設院內診間，或轉介） |
| 拔罐、刮痧、推拿、按摩 | 屬「民俗調理」範疇，可由受訓人員執行，但**不得宣稱療效、不得使用醫療器材** |
| 耳穴壓豆 | 建議由中醫師或在其指導下進行，以「穴位按壓養生」對外說明 |
| 芳療師 | 建議具國際認證（如 IFA / NAHA / IFPA）並有內部培訓與考核 |
| 熱療區監護 | 須有 CPR / AED 證照人員在場 |

## 3. 入住禁忌症篩檢（問卷必問）

高血壓（未控制）、心臟病 / 心律不整、近期手術、孕期與哺乳、癲癇、糖尿病（未控制）、皮膚傷口或感染、靜脈曲張 / 血栓病史、精神科用藥或安眠藥使用中、酒後、重度疲勞或發燒。

> 任一勾選者：熱療、冷熱交替、深層按摩、特定精油需由療癒師 / 中醫師評估後調整或停止；並請客人簽署知情同意書。

## 4. 熱療安全 SOP

1. 熱療前 30 分鐘飲溫水 300–500 ml；熱療中每 15 分鐘提醒補水。
2. 遠紅外汗蒸單次 ≤ 20 分鐘，總時長 ≤ 45 分鐘；藥浴水溫 ≤ 40°C、單次 ≤ 15 分鐘。
3. 冷熱交替：冷池 15–18°C、單次 ≤ 1 分鐘，僅健康評估通過者可參加。
4. 不空腹、不飽腹（餐後 1.5 小時以上），不飲酒。
5. 出現頭暈、心悸、噁心立即停止，移至休息區，量測血壓脈搏。
6. 熱療區設緊急呼叫鈕、AED、急救箱；與最近醫院建立轉診路線（標示車程）。

## 5. 精油安全

- 不口服、不未稀釋直接使用；身體 1–3%、臉部 ≤ 1%、兒童 ≤ 0.5%。
- 孕期避開：迷迭香、鼠尾草、快樂鼠尾草、肉桂、丁香等。
- 癲癇避開：迷迭香、尤加利、牛膝草；高血壓避開：迷迭香、百里香。
- 柑橘類（佛手柑等）有光敏性，按摩後 12 小時避免日曬（或用去光敏佛手柑）。
- 公共空間擴香需低濃度、可關閉，並設「無香區」給敏感者。

## 6. 食療安全

- 菜單標示過敏原；藥食同源食材依衛福部公告「可供食品使用原料」清單選用。
- 孕期、哺乳期、服藥中者，餐點避開活血、寒涼或與藥物有交互作用的食材（如當歸、紅花、薏仁、葡萄柚）。
- 輕斷食套餐僅限健康評估通過者，以「蔬果湯 + 全穀」溫和方案，嚴禁完全斷食、灌腸、催吐。

## 7. 開業前需確認的執照 / 登記

- 觀光旅館或旅館業登記（依規模）
- 餐飲業食品業者登錄、餐飲衛生管理
- 公共浴池 / 溫泉相關衛生規範（若有溫泉需溫泉標章）
- 醫療機構設立（若院內設中醫診間）
- 消防、建築、無障礙、環評（山坡地開發）

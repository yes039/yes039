# ② 客房配置清單

## A｜觀息安睡房（約 35–42 m²）

### 睡眠系統

| 項目 | 規格 / 說明 |
|---|---|
| 床墊 | 獨立筒 + 天然乳膠舒眠層，中等軟硬；可選加硬/加軟墊 |
| 床品 | 天然棉麻、60 支以上；夏季天絲、冬季羽絨被（可換蠶絲被） |
| 枕頭菜單（5 選 2） | 決明子安神枕、蕎麥祛濕枕、記憶棉頸椎枕、乳膠側睡枕、薰衣草香草枕 |
| 窗簾 | 雙層：紗簾 + 100% 全遮光簾（含側邊導軌防漏光） |
| 隔音 | 雙層中空隔音窗、房門密封條、牆體 ≥ STC 50 |
| 節律燈光 | 晨光模式 6500K → 日間 4000K → 傍晚 2700K → 夜間 1800K 琥珀光；全房無藍光夜燈 |
| 白噪音機 | 山林雨聲、溪流、頌缽、粉紅噪音；30/60 分鐘定時關閉 |
| 溫濕度 | 睡眠建議 20–23°C、濕度 45–60%；靜音除濕／加濕一體機 |
| 床頭 | 喜馬拉雅鹽燈、手機收納「睡眠盒」（鼓勵睡前放下手機） |

### 香療系統

- 無水擴香機 + 3 款可替換配方：**安神助眠**／**舒緩焦慮**／**清熱解鬱**（依體質預設）。
- 床頭香囊（依體質）、枕頭噴霧（薰衣草 + 甜馬鬱蘭）。

### 浴室

- 獨立浴缸（深泡型）+ 雨淋花灑；可調色溫燈。
- **體質浴包**（每晚 1 包，管家依體質配置）：

| 浴包 | 配方 | 對應 |
|---|---|---|
| 安眠浴包 | 薰衣草、合歡花、夜交藤、瀉鹽 | S |
| 排濕浴包 | 艾葉、生薑、桂枝、陳皮 | C |
| 清熱浴包 | 薄荷、金銀花、菊花、綠茶 | H |
| 舒鬱浴包 | 玫瑰、佛手、香茅 | L |
| 溫養浴包 | 艾葉、紅花、當歸（低濃度） | Q |

- 天然洗沐備品（無矽靈、植萃），乾刷、浴鹽磨砂膏。

### 陽台與冥想角

- 面山陽台、竹躺椅、毛毯。
- 室內冥想角：蒲團、靜坐墊、冥想引導卡、QR Code 連到館內引導音檔。

### 迷你吧（無酒精、無含糖飲料）

- 體質草本茶包 6 款、礦泉水、椰子水、手作堅果、紅棗枸杞乾果。
- 熱水壺 + 茶具 + 保溫杯。

### 夜床服務（20:30–21:30）

- 調暗燈光切換夜間模式、播放白噪音、擴香切換安神配方。
- 放晚安助眠飲（酸棗仁百合茶 / 小米桂圓露）、明日療程卡、手寫晚安小卡。

| 露台 | 戶外靜坐平台、私人足浴桶（草本足浴） |
| 浴室 | 雙洗手台、檜木泡湯桶、蒸氣淋浴 |

## 全房型共通「不放」清單

- 不放電視（以投影 + 冥想/自然影片取代，可依需求提供）。
- 不放含糖飲料、酒精、泡麵零食。
- 不用人工香精清潔劑（改用天然清潔與純精油）。
- 不設嘈雜的房內冷藏壓縮機（改用靜音冰箱）。

# 觀息谷・療癒度假酒店｜完整設計方案

> **一句話定位**：以《黃帝內經》「治未病」為根，用五感沉浸把「自然療癒、失眠療癒、放鬆療癒、香療、芳療、藥食同源、排毒・排濕・排熱」串成一條**可落地、可複製、可帶回家**的住店療癒閉環。
> 不是 SPA 疊加，而是一套「評估 → 浸潤 → 安睡 → 疏通 → 滋養 → 靜心 → 帶回家」的系統。

## 一、整體理念：一條閉環，七個步驟

```
 入住體質評估 ─▶ 環境浸潤 ─▶ 睡眠修復 ─▶ 身體疏通 ─▶ 食療滋養 ─▶ 靜心放鬆 ─▶ 居家養護方案
  (辨體質)      (自然+香氛)   (失眠療癒)   (排濕/排熱/排毒) (藥食同源)  (音療/冥想)   (療癒帶回家)
       ▲                                                                              │
       └────────────────── 線上回訪 / 下次入住調整方案 ◀──────────────────────────────┘
```

**順序邏輯**：先安心神 → 再調睡眠 → 而後疏通身體 → 飲食補養 → 最後教會客人自己照顧自己。
**自然環境就是第一位療癒師**；香氣是貫穿全場的「隱形動線」。

### 選址條件

- 山林／森林，海拔 600–1,100 m，負氧離子充足、夏季涼爽、濕度可控。
- 有原生植被與水源（溪流、瀑布更佳），遠離主幹道噪音（夜間 < 35 dB）。
- 車程距都會區 1.5–3 小時（週末客可達、又足夠「離開」）。
- 建築低干預：原木、夯土、毛石、竹；大面積落地窗把山、天光、風、鳥鳴引進室內。
- 規模建議：**24–40 間客房**（療癒服務的人力密度決定上限，不宜做大）。

### 五種核心體質（全館分流的依據）

| 代號 | 體質 | 常見表現 | 調理方向 |
|---|---|---|---|
| **H** 濕熱 | 易上火、口苦口黏、長痘、煩躁、舌紅苔黃膩 | 清熱利濕、排熱 |
| **C** 寒濕 | 怕冷、身重、水腫、便溏、舌淡苔白膩 | 溫陽祛濕、排濕 |
| **L** 肝鬱 | 壓力大、易怒、胸悶嘆氣、入睡難 | 疏肝解鬱、放鬆 |
| **Q** 氣虛 | 易累、氣短、易感冒、睡不解乏 | 補氣健脾、溫和不耗 |
| **S** 心神不寧（失眠） | 淺眠多夢、易醒、心悸、思慮多 | 養心安神、助眠 |

> 客人常為複合型（例如「H + S」濕熱合併失眠），系統以「主體質 + 次體質」標示，手環與房卡用顏色標記，全館人員一眼可知。

## 二、空間規劃：七大功能區

### 1）大堂・迎息廳 —— 儀式起點

- 不做華麗裝修：流水水景、原生綠植、低照度暖光。
- **分時香氛**：白天清新草木香（檜木、香茅、佛手柑），傍晚轉沉靜安神香（檀香、雪松、薰衣草）。
- 整點一次 3 分鐘頌缽音，降低交感神經興奮。
- **入住儀式（約 30 分鐘）**：
  1. 換鞋、溫毛巾淨手（體質對應草本水）。
  2. 體質評估：中醫簡易望聞問切 + 問卷 + 睡眠量表（PSQI）+ 壓力量表（PSS）+ 禁忌症篩檢。
  3. 給予**療癒手環**（顏色＝體質）與**個人療癒手冊**（香氛建議、飲食宜忌、課程推薦、身體項目）。
  4. 奉上對應體質的迎賓草本茶。

### 2）療癒客房 —— 失眠療癒核心

全部客房以「深睡」為設計目標：強化隔音、晝夜節律燈光、全遮光窗簾、無藍光夜燈。

- **A｜觀息安睡房（基礎療癒房）**：助眠床墊、枕頭菜單、鹽燈、白噪音機、可切換香薰機、獨立浴缸 + 體質浴包、面山陽台冥想角、無糖草本迷你吧、晚安助眠飲。
- **B｜谷隱療癒套房（3–7 天深度療程）**：加設獨立冥想室、室內芳療護理床、專屬香療台、露台靜坐區，可預約到房芳療。

> 完整清單見 [`02-客房配置清單.md`](02-客房配置清單.md)。

### 3）愈養館 —— SPA 與身體療癒中心

| 分區 | 內容 | 對應需求 |
|---|---|---|
| 芳療香療室 | 獨立單間；全身芳療、頭部香薰頭療、面部香療 | 芳療、放鬆、失眠 |
| 熱療排毒區 | 遠紅外線汗蒸、草本蒸氣（祛濕／清熱兩配方）、草本藥浴池、冷熱交替池、草本熱敷、陶粒熱療 | 排濕、排熱、排毒 |
| 中醫調理室 | 體質辨識、經絡調理、拔罐、刮痧、艾灸、耳穴壓豆 | 治未病 |
| 音療靜心室 | 頌缽、銅鑼、瑜伽 Nidra 睡眠冥想；小班與私教 | 失眠、放鬆 |
| 漂浮放鬆艙 | 高濃度瀉鹽水漂浮 60 分鐘，感官減壓 | 放鬆 |

### 4）食養膳坊 —— 藥食同源餐廳

- 主廚 + 中醫營養顧問共同研發，依**四季 × 體質**定制；自有有機菜園，就地取材。
- 三類菜單：① 日常平衡餐 ② 排濕／清熱／排毒輕食餐 ③ 安神助眠餐。
- 三餐之外：晨間養生茶、午後茶點、夜間安神湯。
- 少油少鹽、少辛辣；**輕斷食套餐需經評估**。
- **食療工坊**：客人親手做藥膳點心、調配養生茶，學會居家食療。

### 5）自然療癒園區 —— 戶外

- 森林浴步道（緩坡 1.2 km + 進階 3 km）、林間冥想平台、溪畔赤足步道。
- **芳香藥草園**：薰衣草、迷迭香、薄荷、艾草、紫蘇、香茅、梔子花、金銀花——既是景觀，也是香療與廚房原料。
- 課程：森林療癒行走、戶外呼吸冥想、晨間八段錦、自然正念、星空靜觀。

### 6）香學工坊 —— 中式香療

- 香道空間：手工製香（安神香、祛濕香、清熱香）、香囊調配、聞香冥想。
- 可選購居家香品，把療癒帶回家。

### 7）靜修學堂

- 每日課表：冥想、呼吸練習、睡眠工作坊、解壓課程、治未病講座；8–12 人小班。

## 三、療癒項目體系（逐項對應你的需求）

### 🌿 自然療癒
森林浴（日本森林醫學的「Shinrin-yoku」步行法）、赤足接地、溪聲冥想、晨光曝曬（調整晝夜節律）、藥草園園藝療癒、星空靜觀。

### 🌙 失眠療癒（入睡難／淺眠／多夢易醒）
1. **硬體**：遮光、隔音、節律燈光、白噪音、草本助眠枕、睡前草本浴。
2. **行為**：白天晨光曝曬 + 午後運動、晚間 20:00 後降光降噪、睡眠衛教工作坊（CBT-I 原則：固定起床時間、床只用來睡覺）。
3. **身體**：香薰頭療、耳穴壓豆（神門、心、皮質下）、頌缽睡眠音療、瑜伽 Nidra。
4. **食療**：酸棗仁、百合、蓮子、桂圓、小米；晚餐清淡、19:00 前完成。
5. **追蹤**：入住與離店各做一次睡眠量表，讓客人「看見」改變。

### 🍃 放鬆療癒（壓力、焦慮、肌肉緊繃）
芳療全身舒緩按摩、熱石療癒、頌缽音療、呼吸正念（4-7-8 呼吸、箱式呼吸）、森林浴、修復瑜伽、漂浮艙。

### 🪔 香療 & 💧 芳療（全場景滲透，雙軌並行）

| 情境 | 中式香療 | 西式芳療 |
|---|---|---|
| 公共空間 | 定時線香、香篆 | 分時段擴香 |
| 客房 | 香囊、助眠香 | 可換配方香薰機 |
| 護理 | 聞香冥想、香灸、線香薰療 | 精油按摩、局部調理 |
| 帶回家 | 手工香、香囊 | 體質複方精油、滾珠瓶 |

**四大配方**：

| 功效 | 精油 | 對應體質 |
|---|---|---|
| 安神助眠 | 薰衣草、甜馬鬱蘭、檀香、岩蘭草 | S |
| 疏肝解鬱 | 佛手柑、苦橙葉、玫瑰天竺葵 | L |
| 清內熱 | 薄荷、尤加利、天竺葵、茶樹 | H |
| 祛濕化濁 | 廣藿香、杜松、薑、絲柏 | C |

> 精油皆需稀釋（身體按摩 1–3%，臉部 ≤1%）；孕婦、癲癇、高血壓者避開特定精油（迷迭香、鼠尾草等），詳見 `06-法規與安全守則.md`。

### 🍲 藥食同源（食療）

| 體質 | 宜 | 示範餐點 |
|---|---|---|
| H 濕熱 | 冬瓜、赤小豆、綠豆、薏仁、馬齒莧、苦瓜 | 冬瓜薏仁排骨湯、綠豆百合甜湯 |
| C 寒濕 | 生薑、茯苓、山藥、肉桂、羊肉、黑糖 | 茯苓山藥燉雞、薑母茶 |
| L 肝鬱 | 玫瑰花、陳皮、佛手、菊花、芹菜 | 玫瑰陳皮茶、涼拌芹菜百合 |
| Q 氣虛 | 黃耆、紅棗、山藥、小米、南瓜 | 黃耆紅棗小米粥 |
| S 失眠 | 百合、蓮子、酸棗仁、桂圓、小米 | 百合蓮子粥、酸棗仁安神湯 |
| 排毒輕食 | 高纖蔬果、全穀、發酵食 | 七色蔬食盤、糙米味噌湯 |

> 食療是日常調養，**不是藥物治療**；菜單標示過敏原與「孕期不宜」品項。

### 🩺 治未病療癒（預防為先）
1. 入住體質評估，建立個人健康檔案。
2. 中醫諮詢：解釋體質成因、生活宜忌。
3. 調理：艾灸、拔罐、經絡疏通。
4. 講座：居家作息、飲食、香療、自我穴位按摩。
5. 離店交付**居家養護方案**（飲食、睡眠、居家香薰、簡易運動）+ 7 天、30 天線上回訪。

### 💨 排毒・排濕・排熱（溫和疏通，不走極端）

**邏輯**：熱療開毛孔 → 代謝排濁 → 芳療淋巴疏通 → 食療收尾。
**嚴禁**：極端斷食、灌腸、催吐、未經評估的高溫長時汗蒸。

| 目標 | 熱療 | 芳療 | 食療 |
|---|---|---|---|
| **排濕**（身重、水腫、苔厚膩） | 遠紅外汗蒸、艾草蒸氣浴、陶粒熱療 | 廣藿香 + 杜松淋巴按摩 | 茯苓、薏仁、赤小豆 |
| **排熱**（口乾、長痘、煩躁） | 薄荷金銀花蒸氣浴、清熱草本藥浴（水溫 ≤ 39°C） | 天竺葵 + 薄荷身體調理 | 清熱祛濕湯、少溫補 |
| **排毒**（代謝減負） | 乾刷 + 草本磨砂、遠紅外發汗 | 淋巴引流按摩 | 排毒輕食、高纖、多喝水 |

> ⚠️ 熱療前後必須補水（每次 300–500 ml 溫水／電解質飲）；高血壓、心臟病、孕期、飲酒後、空腹者不得進入，由療癒師評估。

## 六、核心差異化

1. **全需求閉環**：九大療癒主題串成一條邏輯線，而非項目清單。
2. **體質個性化**：香氛、浴包、餐食、身體項目、課程**全部隨體質切換**；手環顏色讓全館同步。
3. **可量化**：入住與離店做睡眠/壓力量表，客人看得到前後差異。
4. **帶得回家**：居家方案 + 產品 + 線上回訪，療癒延續到日常，也帶來回購。
5. **東方為體、西方為用**：中式香療 + 西式芳療雙軌，治未病理念貫穿全程。

## 七、延伸營收

- **零售**：定制香品、體質複方精油、草本浴包、藥膳茶包、助眠枕。
- **企業**：團體療癒靜修、高管睡眠營、員工身心健康福利。
- **會員**：年度季節調養會籍（四季各住一次，跟著節氣調理）。
- **線上**：居家調養回訪、節氣食療直播、香療居家課程。
